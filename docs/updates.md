# 更新说明

这里记录课程目录、学习资料和阅读功能的更新。

## 2026年10月20日

### 资料预览与下载

- 本站收录的 PDF、Word 文档统一提供“预览”和“下载原文件”入口，下载保留原文件名；Word 可在线查看对应的 PDF 版，也可下载原稿。
- PDF 直接预览原件，支持翻页、缩放和文字查找；通过分段请求按需读取，减少打开页面时的下载量。
- 资料文档分别由基础课、专业课两个资料库提供，预览与下载统一使用本站的 `github.io` 地址。

### 页面阅读

- 隐藏尚无内容的小标题及对应目录项，保留原有定位链接；补入内容后自动显示。

## 2026年10月19日

### 培养方案与课程目录

- 新增26级培养方案课程，补入储能普通班（多能融储、电储）、储能卓工班和未来汽车的课程目录，保留25级及以前的课程资料。
- 各专业课程表按通识必修、专业基础、专业必修、专业选修和实践课程分栏，列出课程号、学分、适用年级与修读要求，区分必修、选修及模块要求。
- 公共课程索引更新适用专业，所有专业均适用的标为“all”。
- 同一专业的毕业设计共用一个入口，分别注明各年级的课程号和学分。
- 跨年级共用的课程合并展示，年级要求有差别时分别注明。
- 数理类补入线性代数、化学、实验和计算机基础课程；相近课程合并展示并注明版本，程序设计资料按语言归集。
- 更新课程名称，保留旧名说明和原有资料入口。

### 课程资料

- 为多门课程补充简介、分数构成及教学大纲。
- 补充计算机、数理基础课和专业课的笔记、练习、回忆题及学习经验；链接注明作者及课程版本，指向CC98原帖或作者、学院学习网站的对应资料页。
- 按实际资料情况统一课程表标注：“✅有资料”“✅较完善”“❌不完善”或“待补充”。

### 导航与阅读

- 顶部能环、储能、车辆菜单支持直接展开选择方向或班型；车辆入口为“车辆工程”“未来汽车”。“本科课程大纲”支持逐级展开。
- 较长的课程简介与教学大纲支持折叠阅读；修正大学物理页的排版和链接格式，适当加粗课程与资料链接。
- 新增更新说明页及首页入口。
- 支持按课程号搜索课程。
