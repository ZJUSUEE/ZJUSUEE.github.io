# 更新说明

## 2026年10月19日

### 培养方案与课程目录

- 新增26级培养方案课程，补入储能普通班（多能融储、电储）、储能卓工班和未来汽车的课程目录，保留25级及以前的课程资料。
- 各专业课程表按通识必修、专业基础、专业必修、专业选修和实践课程分栏，列出课程号、学分、适用年级与选修／必修要求。
- 公共课程索引更新适用专业，所有专业均适用的标为“all”。
- 同一专业的毕业设计共用一个入口，分别注明各年级的课程号和学分。
- 数理类补入线性代数、化学、实验和计算机基础课程；相近课程合并展示并注明版本，程序设计资料按语言归集。
- 更新已确认更名的课程，并注明旧名称，方便查找原有资料。

### 课程资料

- 为新增课程和原有空白课程补充简介、分数构成及教学大纲。
- 为59个课程页面新增97条资料链接，补充笔记、练习、回忆题和学习经验；链接注明作者及课程版本，指向CC98原帖或作者、学院学习网站的对应资料页。
- 按实际资料情况统一课程表标注：“✅有资料”“✅较完善”“❌不完善”或“待补充”。
- 资料文档统一提供在线预览与原文件下载，补入 Word 原稿入口；PDF 预览支持翻页、缩放和文字查找。

### 导航与阅读

- 顶部能环、储能、车辆菜单支持直接展开选择方向或班型；车辆入口为“车辆工程”“未来汽车”。“本科课程大纲”支持逐级展开。
- 较长的课程简介与教学大纲支持折叠阅读；修正大学物理页的排版和链接格式，适当加粗课程与资料链接。
- 新增更新说明页及首页入口。
- 支持按课程号搜索课程。
