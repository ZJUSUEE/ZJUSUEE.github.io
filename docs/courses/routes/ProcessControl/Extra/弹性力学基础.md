# 弹性力学基础

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 弹性力学基础<br><small>ENER3201M</small> | 过控 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程主要涉及弹性力学的基础理论（包括基本概念、基本方程和基本解法）。主要包括三个方面的内容：（1）平面问题的基本理论、求解方法及典型问题的解答；（2）空间问题的基本理论及典型问题的解答；（3）薄板弯曲问题。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考试方式：期末开卷考试。

评价方法：加强过程性考核，强化考核学生的主动参与度，增加考核学生对学科知识的理解深度。

成绩构成比例：期末开卷考试占70％，课程作业、课堂回答问题与出勤率占30％。
