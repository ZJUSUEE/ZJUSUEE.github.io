# 过程装备与控制工程技术进展

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 过程装备与控制工程技术进展<br><small>ENER4205M</small> | 过控 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    结合国家及区域重大需求和国防安全，介绍本学科开展的具有前瞻性、先导性、探索性和共性的技术研究内容，主要包括承压设备安全与过程优化、过程装备数字化技术、过程机械创新设计和控制三个方面。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本门课程的评分分为2个部分，出勤和讨论：60％；课程报告：40％。

### 课程大纲

??? abstract "展开查看"

    第1-6次：承压设备安全与过程优化方向研究进展（12学时，线下）

    课外学习与作业要求：查阅承压设备安全与过程优化方向的相关国家关于过程装备设计、开发、研究、环境保护和安全防灾等方面的方针、政策和法规。

    第7-11次：过程装备数字化技术方向研究进展（10学时，线下）

    课外学习与作业要求：查阅相关资料，了解过程装备数字化技术方向研究进展动态。

    第12-16次：过程机械创新设计和控制方向研究进展（10学时，线下）

    课外学习与作业要求：查阅相关资料，了解过程机械创新设计和控制方向研究进展动态。
