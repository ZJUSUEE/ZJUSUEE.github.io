# 车辆振动与噪声

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |

## 课程简介

??? abstract "展开查看"

    本课程是介绍车辆振动与噪声控制技术的专业课，内容包括车辆与发动机NVH技术发展概述、声学分析基础、振动分析基础、车辆主要振动噪声源识别、车辆声品质分析、车辆振动噪声控制、车辆振动噪声基本实验方法等。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考试方式：期末开卷测验。

评价方法：加强过程性考核，强化考核学生的主动参与度，增加考核学生对学科知识和课程思政有机结合的理解深度。

成绩构成比例：

主动参与：10%，课堂讨论和报告分享；

平时作业：20%，其中2次课程作业融入课程思政元素，设置与中国汽车产业NVH性能研发相关的开放式问题；

考勤：10%，考察学生到课情况；

期末开卷测验60%。

### 课程大纲

??? abstract "展开查看"

    第一章 绪论 车辆振动噪声研究的发展

    1. 汽车NVH概念及其研究的发展

    2. 汽车噪声控制法规

    3. 车辆噪声的评价指标

    4. 常见的振动噪声实验室

    5. 常见的车辆振动噪声试验

    6. 车辆NVH技术的前沿发展方向

    第二章 振动基础

    1. 振动测试介绍

    2. 单自由度机械振动系统的受迫振动

    3. 振动分析理论及应用

    4. 人体对振动的响应

    第三章 声学基础

    1. 声学基本概念

    2. 理想流体介质中基本声学方程的建立

    3. 声波的传播与反射

    4. 声级的评估、计权及倍频程分析

    5. 声场的分类

    6. 噪声源识别方法

    第四章 噪声源识别

    1. 噪声源识别的分类

    2. 传统噪声源识别方法

    3. 基于声振列的噪声源识别方法

    4. 基于信号处理的噪声源识别方法

    第五章 声品质分析

    1. 心理声学基础概念

    2. 客观声品质参数

    3. 主观声品质分析

    4. 声品质分析案例

    第六章 车辆振动噪声控制

    1. 动力系统振动噪声控制

    2. 车辆振动噪声控制

    车辆振动噪声实践课，演示车辆振动噪声测试和人因声振舒适性的测试内容。

    专家进课堂研讨课/总结。
