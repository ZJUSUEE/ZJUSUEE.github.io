# 汽车工程导论

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 汽车工程导论<br><small>ENER1404M</small> | 车辆 · 25级及以前<br>**专业必修** |

## 课程简介

??? abstract "展开查看"

    本课程是汽车工程专业新生的引导性课程，主要内容包括：1）汽车发展历史及汽车相关基础知识的讲授：如汽车品牌、汽车编码、车辆识别代码等；2）传统汽车发展的技术介绍，如排放控制的技术以及技术发展的趋势，汽车噪声、振动的控制及轻量化设计等；3）新能源汽车技术、智能汽车、车联网等新技术介绍；4）中国、国际汽车及发动机技术发展现状、生产规模以及未来发展趋势介绍等。由于汽车本身技术复杂，种类丰富，知识范围覆盖非常广泛，这门课旨在培养车辆工程专业学生对汽车方向的兴趣，让学生们掌握汽车发展的历史、核心技术、前瞻科技、国内外环境及未来发展趋势等。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

到课情况（出勤、课堂发言）10%，课程作业90%。

### 课程大纲

??? abstract "展开查看"

    第一次：能源变革与汽车发展历史（2学时理论+1学时讨论）

    第二次：汽车动力能源技术的发展（2学时理论+1学时讨论）

    第三次：双碳战略下内燃机机遇、挑战和对策（2学时理论+1学时讨论）

    第四次：新能源汽车技术（2学时理论+1学时讨论）

    第五次：智能汽车及物联网（2学时理论+1学时讨论）

    第六次：汽车热管理技术（2学时理论+1学时讨论）

    第七次：汽车发动机振动噪声控制技术（2学时理论+1学时讨论）

    第八次：人因振动工程（2学时理论+1学时讨论）

    主要内容：介绍国外、国内汽车及发动机领域的技术现状，生产规模，以及未来的发展趋势。以学生为主体，结合技术现状、社会背景、宏观形势与中国的发展方向，讨论汽车未来发展趋势与自身应承担的历史使命。
