# 低温生物技术

## 课程信息 {#course-information}

## 课程简介

??? abstract "展开查看"

    本课程的基本内容为制冷与低温在生物材料保存和医疗器械上的应用，主要包括：一、低温生物医学技术的概述：研究范围和发展历史。二、水和水溶液的基本性质：低温下的结晶、过冷和玻璃化现象。三、低温对于细胞和生物组织的作用影响。四、细胞和生物组织的低温保存：低温保护剂，冷冻保存和玻璃化保存，低温保存的应用。五、低温医疗：原理、器械和应用。六、冷冻干燥保存：设备和原理，微生物、药物和哺乳动物细胞的冷冻干燥保存。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    第一周：低温生物技术概述

    主要内容：低温生物医学技术涉及低温、生物及医学等学科的交叉，结合点体现在何处？低温生物学发展简史。

    第二周：水和水溶液的冷冻

    主要内容：水和水溶液是生物体中最重要的组成成分，研究水溶液的冷冻对于研究低温下生物体的反应具有重要参考价值，本周介绍水溶液的基本性质、水的结冰和过冷现象、二元溶液的相图、三元溶液的相图。

    课后作业：渗透压、冰点、结冰比例的计算。

    第三周：低温保存（一）

    主要内容：低温保护剂、低温显微镜。

    第四周：低温保存（二）

    主要内容： 悬浮细胞的低温保存及物理建模，器官的低温保存，低温保存设备、低温保存的应用。

    课后作业：细胞冷冻过程的计算

    第五周：低温保存小实验

    主要内容：分组进行小鱼、血液细胞低温保存小实验。

    第六周：低温医疗

    主要内容：低温医疗的原理、治疗器械。

    第七周：冷冻干燥保存（一）

    主要内容：冷冻干燥原理、冷冻干燥设备。

    第八周：冷冻干燥保存（二）

    主要内容：微生物和药物的冷冻干燥、哺乳动物细胞冷冻干燥。
