# 制冷与人工环境英语

## 课程信息 {#course-information}

## 课程简介

??? abstract "展开查看"

    《制冷与人工环境英语》是一门专业选修课程，结合专业外语和专业前沿两方面的知识，旨在提高学生的外语实际应用能力，并全面了解专业发展现状。在课程内容方面上，首先从实用的角度出发，结合制冷与低温工程专业知识，系统地介绍专业英语的语法特点、文体结构、词汇及语篇特点、专业英语翻译和专业论文的写作等基础知识。通过大量有针对性的专业阅读材料（范围涉及到制冷与低温、暖通和空调），让学生对专业内的英语表达有比较全面的了解。此外，还介绍国际交流中的实用写作内容，如个人简历、推荐信、国际合作协议、项目申请书、国际会议文件和论文投稿等。在实践环节，通过主题文献调研、综述论文写作以及最后的英文口头报告，使学生在掌握相关专业前沿进展的同时，锻炼各方面的综合能力。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

期终闭卷考试（时间1.5小时）

总评成绩 = 期终考试成绩×30％＋平时成绩×70％

其中，平时成绩70% =书面报告20% +口头报告20% +PPT展示10%+ Poster展示10% +课堂表现10%。

### 课程大纲

??? abstract "展开查看"

    每周课堂教学3学时，共8周。

    第一周：

    主要内容：为了对“制冷与低温”学科有一个概括性的认识，参照国际制冷学会的各个委员会的设置情况以及它们各自的学科内容进行介绍。国际制冷学会共有10个委员会，即A1/A2, B1/B2, C1/C2, D1/D2, E1/E2，它们相对应的学科主题分别为：Cryoengineering、Liquefaction of gases、Cryobiology、Refrigerants、Refrigerating equipment、Food technology、Refrigerated storage、Refrigerated transport、Air conditioning 和Heat pumps等。

    第二周：

    主要内容：介绍专业英语的基础知识，主要从与普通英语的区别出发，对专业英语在语法、文体结构、词汇和语篇等方面的特点进行有针对性的阐述，让学生了解在使用专业英语的过程中应该注意的基本原则，并有利于他们在后续阅读、撰写专业范围内的英文材料时能够灵活应用。

    第三周：

    主要内容：专业科技文献的翻译是介绍国外科学技术的桥梁，它对于推动我国在尽可能短的时期内赶超世界先进的科学技术水平，加快本民族经济和文化的发展有着重要的意义。本次课将安排介绍翻译的标准、过程，对译者的要求，英汉语言特点的对比，专业英语翻译的基本方法，专业英语中术语的翻译以及专业英语中数量的翻译等内容。

    第四周：

    主要内容：基于科技论文的特点，将系统介绍专业英语论文写作的基本格式和要求以及在论文投稿过程中所要碰到的各个程序。着重围绕科技论文所包含的标题(Title)、目录(Content)、提要(Abstract)、引言(Introduction)、正文(Body)、结论(Conclusion)、致谢(Acknowledgement)、参考文献(Reference)、附录(Appendix)等组成部分，详细介绍了其特点及常用格式。

    在此环节，特别强调学术伦理、道德和规范对于一位学者学术生命的重要性，引导学生树立正确的学术价值观。

    第五周：

    主要内容：文献阅读是一项基础性的工作，是完成个人对专业领域知识积累的重要途经。本次课重点介绍如何获取相关科技文献（包括文献来源和搜索技巧等），学术论文的分类，整理方法，阅读技巧，文献综述等知识。

    此外，在科技领域的国际交流中，相关文字资料的书写是必不可少的。本次课主要介绍一些常见的实用写作范例，包括求职（学）信、履历表、个人陈述和推荐信，科研基金申请表，国际合作协议，新闻稿，国际会议和产品说明书等。在此环节，强调在国际交流中要时刻注意怀有知识产权保护和坚持爱国情怀等意识。

    第六周至第八周：

    学生进行专题报告和展示。报告会以国际会议的模式进行组织安排，每组报告人安排10分钟的口头报告，其余5分钟进行听众提问，报告及提问环境采用全英文模式。最后，主持人（主讲教师担任）对报告和提问情况进行评价或补充。与此同时，每一个小组要准备一份墙报，并进行集中展示。小组之间进行相互参观学习和相互提问。

    在此环节，强调在学术交流过程中要勇于质疑、敢于提问，又要相互理解和相互尊重。
