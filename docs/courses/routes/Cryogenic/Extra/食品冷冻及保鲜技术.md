# 食品冷冻及保鲜技术

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 食品冷冻及保鲜技术<br><small>ENER3011M</small> | 低温 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程是一门应用性强、知识综合度大的专业课程。综合了食品生物化学、食品微生物学、物理化学、制冷原理、工程热力学和传热学等方面的知识运用。它包括食品冷冻原理、食品冷冻的物理化学基础、食品的冷却与冷藏、食品的冻结与冻藏、食品的玻璃化转变与储藏、食品的冷冻干燥和食品的升温与解冻七个部分。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

期末开卷考试占50％，课程作业占50％。

### 课程大纲

??? abstract "展开查看"

    第一周：绪论、第一章 食品冷冻原理

    主要内容：介绍食品冷冻工程的发展历史及主要研究内容；介绍第一章食品冷冻原理中的食品生物化学基本知识。

    第二周：第一章 食品冷冻原理

    第三周：第二章 食品冷冻的物理化学基础、第三章 食品的冷却与冷藏

    主要内容：介绍食品的冷冻特性和食品的热物理性质及其估算介绍；介绍第三章食品的冷却与冷藏中的食品冷却与冷藏工艺、设备、热负荷计算。

    第四周：第三章 食品的冷却与冷藏

    主要内容：介绍冷却时间计算，包括导热微分方程及其求解；零维食品、一维食品、二维食品、三维食品。

    第五周：第四章 食品的冻结与冻藏

    主要内容：介绍食品冻结和冻藏工艺以及相应的设备；介绍食品冻结过程的热负荷计算以及冻结时间计算。

    第六周：第五章 食品的玻璃化转变与储藏

    主要内容：介绍食品玻璃化转变的机理、途径和应用。

    第七周：第六章 食品的冷冻干燥

    主要内容：介绍食品冷冻干燥的方法、工艺、设备、应用和热力计算。

    习题7：食品冷冻干燥方法的特点是什么？

    第八周：第七章 食品的升温与解冻

    介绍食品升温与解冻的工艺和方法。
