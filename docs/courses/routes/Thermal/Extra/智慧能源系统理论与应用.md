## 课程简介

??? abstract "展开查看"

    当前，我国正在推进能源生产与消费革命，风能、太阳能等可再生能源不断渗入传统以化石燃料为主的能源系统，分布式能源、多能互补、能量系统集成、储能、电动汽车等技术正蓬勃发展，能源技术与信息技术的融合不断加深，整个能源系统正快速向更为清洁、更为低碳的智慧化模式和业态发展。本课程为能源与环境系统工程方向专业选修课，针对智慧能源系统的相关原理与实践，讲授智慧能源系统所涉及的规划设计和分析评价方法，结合案例分析和专题讨论，使学生掌握智慧能源系统的规划设计、运行维护知识，为学生毕业后参与能源系统的变革和转型工作奠定基础。本课程采用课程讲授、文献阅读自学和课堂讨论相结合的教学方法，考核采用课程作业及读书报告的形式。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考核方式注重考察学生的能力和素质，细化课程总成绩得分点，加强过程性考核。课程总成绩由到课率、课堂讨论表现、课外阅读报告、平时作业、课程论文等多部分组成，突出课程的过程性评价和过程管理。其中到课率和课堂讨论表现占 40%，课外阅读报告、课程论文占60%

### 课程大纲

??? abstract "展开查看"

    （一）智慧能源系统的概念与内涵 4学时

    1. 能源行业所面临的挑战和智慧能源的愿景 0.5学时

    2. “智慧”的意义 0.5学时

    3. 智慧能源系统总体框架和所涉及的关键组成部分 2学时

    4. 智慧能源系统的代表性案例 1学时

    （二）智慧能源系统的感知层与传输层 4学时

    1. 信息物理系统的含义和应用 1.5学时

    2. 微型处理器与智能传感器 1学时

    3. 新一代无线通讯技术 1学时

    4. 信息安全问题 0.5学时

    （三）智慧能源系统大数据 4学时

    1. “大数据”的意义 1学时

    2. 人工神经网络法 1学时

    3. 大数据方法的局限性与优势 1学时

    4. 能源系统大数据应用案例 1学时

    （四）智慧能源系统规划与设计 6学时

    1. 传统能源系统的规划与设计 1学时

    2. 智慧能源系统的规划与设计原理 2学时

    3. 微网的概念与规划 1学时

    4. 能源梯级利用的概念与设计 1学时

    5. 能源系统规划设计案例 1学时

    （五）全生命周期分析方法 4学时

    1. 工业生态学原理 0.5学时

    2. 全生命周期分析方法的概念和原理 1学时

    3. 全生命周期分析方法的一般流程 1.5学时

    4. 全生命周期分析方法应用于能源系统评估的案例 1学时

    （六）能源系统的经济性分析 4学时

    1. 平准化能源成本的概念和分析 0.5学时

    2. 新能源发电技术的系统变化性成本 2.5学时

    3. 学习曲线理论和应用 1学时

    （七）课程总结 6学时

    1. 智慧能源的“源、网、用”整体协调优化 2学时

    2. 学生汇报总结 4学时
