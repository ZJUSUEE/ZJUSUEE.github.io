# 太阳能发电

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 太阳能发电<br><small>ENER3049M</small> | 热能 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程适用于能源与环境系统工程专业方向，引导学生系统掌握太阳能发电技术及应用方面的知识。对目前太阳能发电技术基础知识和研究进展做详细的介绍，包括太阳能的基本知识、太阳能聚光原理与设计、太阳能集热储能原理和设计、光热发电和光伏发电技术前沿和应用前景等。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考勤占20％，平时表现与讨论发言占30％，作业占50％。

考核方式：期末大作业。

评价方法：加强学习过程的考核，强化考核学生的主动参与度，增加学生对太阳能知识和课程思政有机结合的理解深度。

成绩构成比例：

课堂纪律20%，通过点名来进行考察，每次考勤都到为满次，严重迟到或两次请假为半次，不到或每三次请假扣1次，按比例记分；

讨论课发言30%：通过课堂讨论、习题分析、现场答疑和讨论等方式，考察学生的知识理解与灵活应用能力，根据讨论或回答问题情况评分；

课堂考查与课后作业50%：课外拓展性学习和课程思政研习；根据授课内容布置课后作业，根据提交作业的质量进行评分。

### 课程大纲

??? abstract "展开查看"

    第1次 太阳能概论：

    太阳辐射的基本概念，太阳高度角和太阳方位角，日照时间和太阳能资源区划，大气对太阳辐射的吸收和散射及大气透明度，太阳直辐射和天空辐射，太阳辐射量的工程处理，太阳能利用的总体现状、市场应用情况、中国及国外发展趋势等等。

    思考题：未来能源系统的分析与展望

    第2次 太阳能光学设计原理：

    太阳光的聚光特性、太阳能圆面张角对聚光器设计的影响规律，分析菲涅尔透镜的原理，讨论聚光器的几何聚光比、能量聚光比以及最大聚光比等等

    思考题：太阳能复合抛物面CPC聚光的数学原理。

    第3次 太阳能光学设计原理：

    掌握槽式抛物面聚光器、旋转抛物面聚光器与圆形接收器的理论分析方法和设计原理，探讨镜面利用系数与聚光比之间的变化规律等等。

    思考题：由于太阳张角的影响，理论聚光比最高可以多大。

    第4次 光伏发电技术：

    太阳能光伏电池的半导体的光敏特性、温敏特性、N型和P型半导体的概念、N-P结的形成、光伏效应及太阳能电池的工作原理等等。

    思考题：光生载流子大量产生时，PN结上的电子运动状况——光伏电池的基本原理。

    第5次 光伏发电技术：

    等效电路、伏安特性曲线、填充因子、转换效率、开路电压、短路电流、光谱响应、标准化测试原理、装置及测试方法、光伏电池中的储能问题、蓄电池的主要类型、效率及其问题分析等等。

    思考题：各种类型的太阳能光伏技术的发展与应用状况。

    第6次 光热发电技术：

    太阳能热发电技术的发展趋势与前景、集热器设计原理、太阳能光-热转换原理及工艺系统、太阳能槽式光热发电系统原理与装置、太阳能塔式光热发电系统原理与装置等等。

    第7次 光热发电技术：

    太阳能碟式光热发电系统原理与装置、斯特林机发电装置及其原理、太阳能发电系统中蓄热储能的意义及方法等等。

    思考题：选出自己最感兴趣或是认为最具发展前途的部分为主题，做好展示ppt。

    第8次 太阳能光伏、光热及热利用技术的基本知识总结、对比分析，讨论前沿进展和未来展望等。

    同学们根据自己的兴趣和疑问，做ppt展示，并与大家讨论。
