# 可再生能源和新能源概论

## 课程简介

??? abstract "展开查看"

    本课程内容包括：1.绪论。讲授可再生能源和新能源的概况，中国和世界能源分布、结构和消耗情况，新能源分类、发展概括和应用前景。2.太阳能。讲授太阳能光伏发电技术、热利用技术、动力利用技术、光化利用技术等的工作特点、原理、系统和工艺。3.风能。讲授风与风力资源，风力发电技术原理和工作过程，风力发电现状与展望。4.生物质能。讲授生物质能资源和利用现状、前景，生物质能转化技术和发电技术，生物质能裂解发电技术。5.海洋能。讲授海洋能分类，潮汐和潮汐能概括，潮汐能发电技术，中国和世界潮汐能发电概括和前景。6.地热能。讲授地热能资源和开发技术概括，地热能发电原理、分类和工作过程。7.氢能。讲授各种氢气的生产技术和方法，氢能的转化、储存、输运技术，氢能的终端利用技术。8.其他新能源。讲授其他新能源技术，如核聚变、水能、可燃冰等。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本门课程的评分分为2个部分，每个部分分数分配如下：平时成绩（主要针对平时作业情况）：20％；期末考试卷面成绩：80％。

### 课程大纲

??? abstract "展开查看"

    第一周：课程介绍和可再生能源和新能源基础

    介绍课程目标和内容安排。

    引导学生思考可再生能源和新能源对社会、环境和经济的影响。

    解释可再生能源和新能源的概念和定义。

    讨论可再生能源和新能源的分类和特点。

    分析可再生能源和新能源在全球能源结构中的地位和发展趋势。

    通过本周的学习，学生将对可再生能源的基本概念有所了解，并了解到可再生能源在全球能源结构中的重要性和发展趋势，为后续学习打下基础。

    第二周：太阳能

    太阳能的产生原理：介绍太阳辐射的特点以及太阳能是如何被转化为可利用的能源的。

    太阳能的利用方式：讨论太阳能在光伏发电和热利用方面的不同应用技术，包括光伏组件、太阳能热水器和太阳能发电热发电等。

    光伏技术原理：介绍光伏效应和太阳能电池的工作原理。

    光伏组件和系统：讨论光伏组件的种类和结构，以及光伏系统的设计和配置。

    太阳能光伏发电应用：探讨太阳能光伏发电在家庭、商业和工业领域的应用案例和发展情况。

    太阳能热利用原理：介绍太阳能热利用技术的工作原理，包括太阳能热水器和太阳能发电热发电系统。

    太阳能热水器：讨论太阳能热水器的工作原理、类型和应用场景。

    太阳能发电热发电：探讨太阳能发电热发电系统的工作原理和应用领域。

    课堂作业：

    小组讨论，准备太阳能在特定领域的应用案例分析报告。

    通过本节课的学习，学生将对太阳能的原理、应用技术和发展趋势有所了解，并为进一步深入学习相关领域奠定基础。

    第三周：风能

    风能的产生原理：解释地球大气环流和地形地貌对风能的影响，说明风能是如何被转化为可利用的能源的。

    风能的利用方式：讨论风力发电的工作原理和发电机组的构造，介绍风能在风电场中的应用情况。

    风力发电技术原理：介绍风力发电机组的工作原理和发电过程。

    风力发电机组构造：讨论风力发电机组的主要构成部分，如风轮、发电机和控制系统等。

    风场规划：探讨风电场建设的选址、设计和规划过程。

    风能资源评估方法：介绍风能资源评估的基本原理和常用方法，包括测风塔观测和数值模拟等。

    风电场布局设计：讨论风电场布局设计的考虑因素和技术要点，如风机间距、排列方式和阵列布局等。

    通过本节课的学习，学生将对风能的原理、应用技术和发展趋势有所了解，并为进一步深入学习相关领域奠定基础。

    第四周：生物质能

    生物质能的来源：解释生物质能是如何来自生物体的有机物质，包括植物、动物和微生物等。

    生物质能的特点：讨论生物质能的可再生性、广泛性和低碳性等特点，说明其在能源领域中的重要性。

    生物质能转化技术原理：介绍生物质能转化为生物质电力或液体燃料的基本过程和机制。

    生物质发电：讨论生物质发电技术的发展现状和主要技术路线，包括生物质燃烧发电和生物质气化发电等。

    生物质液体燃料生产：探讨生物质液体燃料的生产工艺和应用领域，如生物柴油和生物乙醇等。

    生物质能的可持续管理：介绍生物质能资源的管理和保护措施，包括生物质能的种植、采集和利用方式等。

    社会经济影响：分析生物质能产业对经济发展、就业和环境改善等方面的影响。

    生物质能的发展前景：探讨生物质能作为可再生能源的发展趋势和挑战。

    课堂作业：

    小组讨论，准备生物质能在特定地区的应用案例分析报告，并进行汇报。

    阅读相关文献或报告，撰写个人学习笔记或总结。

    本周课程将使学生全面了解生物质能的来源、转化技术和可持续利用策略，为他们深入研究生物质能领域提供基础知识。

    第五周：海洋能

    海洋能的定义和分类：介绍海洋能是指从海洋中获取能量的过程，主要包括潮汐能和波浪能。

    海洋能的产生原理：解释潮汐能和波浪能的形成原理，包括地球引力和海洋运动等因素。

    海洋能的特点：分析海洋能的稳定性、持续性和潜在能量储备等特点。

    潮汐能利用技术：介绍潮汐能发电站的构造和工作原理，包括潮汐水库和潮汐涡轮发电机组。

    波浪能利用技术：讨论波浪能发电装置的设计和应用，包括浮式波浪发电机和海底波浪能转换器等。

    海洋能发电技术的发展现状和未来趋势：分析海洋能发电技术在全球范围内的应用情况和市场前景。

    通过本章节的学习，学生将对海洋能的产生原理、利用技术和发展前景有所了解，为他们深入学习和研究海洋能领域奠定基础。

    第六周：地热能

    地热能的定义和分类：介绍地热能是指地球内部储存的热能，主要包括地热热泵和地热发电。

    地热能的产生原理：解释地热能的产生机制，包括地球内部的地热流体和地热岩石。

    地热能资源的分布特点：分析地热能资源在全球范围内的分布情况和差异性。

    地热热泵技术：介绍地热热泵的工作原理和应用场景，包括采暖、制冷和热水供应等方面。

    地热发电技术：讨论地热发电的主要方法，包括干蒸汽地热发电和闪蒸汽地热发电等技术。

    地热能发电技术的发展现状和未来趋势：分析地热能发电技术在全球范围内的应用情况和市场前景。

    通过本章节的学习，学生将对地热能的产生原理、利用技术和发展前景有所了解，为他们深入学习和研究地热能领域奠定基础。

    第七周：氢能

    氢能的定义和分类：介绍氢能是指通过水解、化石燃料加氢或电解水等方式获得的氢气。

    氢能的产生原理：解释氢能的产生机制，包括水解反应、甲烷蒸汽重整和电解水等过程。

    氢能的特点：分析氢能的高能量密度、清洁性和可再生性等特点。

    氢能在交通运输领域的应用：介绍氢燃料电池车辆和氢气内燃机车辆的技术原理和发展情况。

    氢能在工业生产领域的应用：讨论氢气作为化工原料、合成氨和金属加氢等方面的应用。

    燃料电池技术：详细介绍燃料电池的原理、构造和应用领域，包括聚合物电解质燃料电池和固体氧化物燃料电池等。

    通过本章节的学习，学生将对氢能的产生原理、利用技术和应用领域有所了解，为他们深入学习和研究氢能领域奠定基础。

    第八周：其它新能源及节能技术

    核聚变的基本原理：介绍核聚变是如何利用轻元素的核融合释放出大量能量的物理过程。

    核聚变技术的应用前景：探讨核聚变技术在未来清洁能源产业中的作用和潜在应用领域。

    水能的利用方式：介绍水能是如何通过水力发电和潮汐能利用等方式转化为电能的。

    水能资源的分布和利用：讨论全球水能资源的分布情况和各国水电站建设的现状。

    可燃冰的开发与利用：解释可燃冰是如何在海底沉积形成的，以及如何进行开采和利用。

    节能技术的意义：解释节能技术对能源资源的节约和环境保护的重要性。

    节能技术的分类：介绍节能技术按照应用领域的分类，如建筑节能、工业节能和交通节能等。

    节能技术的应用和发展：讨论各种节能技术在实际应用中的情况和发展趋势，包括节能材料、节能设备和节能管理等方面。

    通过本章节的学习，学生将对其他新能源和节能技术有所了解，并了解其在可持续发展中的重要性和应用前景。
