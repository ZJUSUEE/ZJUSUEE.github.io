# 燃料电池

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 燃料电池<br><small>ENER3043M</small> | 新能源 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    燃料电池概论主要介绍燃料电池原理和各种燃料电池的特性和发展现状，是能源与环境、新能源与可再生能源类专业的一门重要技术基础课。课程涉及与燃料电池相关的电化学、材料、环境和微生物的基础知识，主要内容包括燃料电池概述、电化学基本知识、燃料电池基本参数、质子交换膜燃料电池、碱性燃料电池、熔融碳酸盐燃料电池、固体氧化物燃料电池和微生物燃料电池。通过本课程学习，学生能够掌握燃料电池基本原理和相关学科的基础知识，了解燃料电池的发展和应用。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

平时（上课与作业）40%，期末大作业考核（书面报告+PPT口头展示）60%

### 课程大纲

??? abstract "展开查看"

    （1）概述 2学时

    1．能源和环境面临的挑战，新能源、储能、减排、碳中和等热点

    2.燃料电池定义

    3.燃料电池种类

    4.燃料电池的现状与未来的发展

    （2）电化学基础理论 2学时

    1.电化学反应简介

    2.电极电位

    3.电极过程动力学

    （3）燃料电池的基本参数 2学时

    1.功率与功率密度

    2.电流与电流密度

    3.电池效率

    4.电池极化现象

    （4）质子交换膜燃料电池 7学时

    1.电池结构与电池材料

    2.催化剂和质子交换膜

    3.膜电极装备方法和结构

    4.H2-O2电池

    5.DMFC

    6.其它燃料的电池

    7.质子交换膜燃料的特性与应用

    8.燃料电池实物演示

    （5）碱性燃料电池 1学时

    1.电极反应与电极过程动力学

    2.电池特性

    （6）熔融碳酸盐燃料电池 1学时

    1.电池结构与电极反应

    2.电池特性与应用

    （7）固体氧化物燃料电池 2学时

    1.固体氧化物燃料电池的电极材料

    2.固体氧化物燃料电池的结构

    3.固体氧化物燃料电池的特性与应用

    （8）微生物燃料电池 5学时

    1.微生物燃料电池的原理

    2.微生物燃料电池的特性

    3.微生物燃料电池的应用前景

    4.其它微生物电化学系统

    （9）燃料电池在未来能源可持续发展体系中作用与挑战 2学时

    1.燃料电池与其它能源体系的耦合

    2.大规模储能和电动汽车动力电源系
