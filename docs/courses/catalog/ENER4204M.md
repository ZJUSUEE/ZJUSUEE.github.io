## 课程简介

??? abstract "展开查看"

    《过程装备课程设计》这门课程通过典型产品的生产过程的介绍，要求学生了解工艺流程图，在此基础上能够进行工艺计算，并可以对工艺流程中相关过程装备进行设计，包括各个典型设备（储存设备、反应设备和塔设备）的设计条件表和施工图；使同学具备初步的过程装备的设计和应用能力。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

出勤：10％；课堂设计讨论：10％；课程大作业（设备设计条件表、一张2＃手工工程图纸、设计说明书）40％；设计图纸答辩成绩：40％。

### 课程大纲

??? abstract "展开查看"

    第一次：课程设计任务安排、工艺流程介绍（讲授）

    主要内容：典型产品的生产工艺以及工艺流程图介绍；各个设备的设计要点,包括种子罐、消毒罐、发酵罐、加湿塔、储水罐；设备设计条件图的绘制，包括简图与说明、设计参数与要求、接管表（法兰以及密封面型式）。常用标准介绍；课程设计任务分解及布置。

    说明：储存设备、反应设备和塔设备的分组设计（一人一题）。

    参考材料：典型化工设备机械设计指导（课堂提供）；化工容器设计资料汇编（课堂提供）；丁字尺；典型设备施工图；《过程装备成套技术设计指南》，黄振仁、魏新利，化学工业出版社，2002.12；

    电子版本的设计资料：

    设计标准：

    GB/T 150-2011 压力容器

    TSG 21-2016 固定式压力容器安全技术监察规程（容规）

    NB/T47042-2014 钢制卧式容器

    HG/T20580-2011 钢制化工容器设计基础规定

    HG/T20581-2011 钢制化工容器材料选用规定

    HG/T20582-2011 钢制化工容器强度计算规定

    HG/T 20583-2011 钢制化工容器的结构设计规定

    HG/T 20584-2011 钢制化工容器的制造技术要求

    零部件标准：

    NB/T 47020~47027-2012（压力容器法兰,垫片、紧固件）

    HG/T20592-2009 （ 钢制管法兰 ）

    NB/T（47065.1-47065.5）-2018 ( 容器支座 )

    第二次：分设备顺序讨论设备设计条件表（讨论课）

    设备图的表达，包括视图绘制、技术要求、技术特性表、管口表、标题栏以及明细表；压力容器分类；常用材料；管子规格以及布管范围；标注基准；支撑型式。

    1、 简图与说明，包括压力容器本体、主要内件形状、结构尺寸、接管位置、安装支承型式、其它必要的图形。

    2、设计参数与要求，包括工艺的提出要求，如工作压力、工作温度、介质、特性、腐蚀裕度、密封要求等。

    3、 接管表，包括公称直径、公称压力、密封面型式、法兰结构型式（类型、用材以及密封面型式）

    第三次：设备设计条件表（课堂指导）

    设备的工艺计算，绘制设备条件图。包括：简图与说明；设计参数与要求；接管表等。

    第四次：分设备顺序讨论施工图的设计（讨论课）

    种子罐、消毒罐、发酵罐、加湿塔、储水罐五种设备的设计参数不同分组设计，并从设计材料、零部件标准、制造检验等方面进行讨论。

    1、同学参考大图明细栏，在现有零部件基础上添加零件，确定新的名称及图号等。

    2、总图的图号确定，以及搭积木画法。

    3、盘管拆装、支撑盘的固定、单面焊、人孔加爬梯等。

    第五次：施工图的设计（课堂指导）

    设备结构计算与设计的指导。

    第六次：施工图的绘制（课堂指导）

    结合具体图纸课堂指导。包括：表达方式、图样的简化画法、焊接接头等。

    第七次：施工图的绘制（课堂指导）

    结合具体图纸课堂指导。包括：图号、标题栏、明细表等。
