# 过程装备数字化实训

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 过程装备数字化实训<br><small>ENER3224M</small> | 过控 · 25级及以前、26级<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    本课程主要介绍过程装备实验以及数字化技术在过程装备实验中的应用，包括三个方面的内容：一、过程装备数字化实训的基础，主要介绍实验设计、数据采集、数据处理等实验基础知识，以及数字化实训常用的软件。二、过程装备中三类典型研究对象的数字化实训，主要包括压力容器、流体增压机械、过程装备控制的实验原理、实验操作、数值模拟和虚拟仿真技术；三、大数据和数字孪生技术在过程装备实验中的应用，包括过程装备状态智能识别实验和典型过程装备数字孪生开发实训。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

期末开卷考试，考试成绩占30%，实验课及实验报告占50%，课后作业及论文占20%。

### 课程大纲

??? abstract "展开查看"

    第一周：过程装备知识体系及实训概述（5课时）

    主要内容：1、概述过程装备的知识体系，梳理过程设备、机械、控制等的关联关系，形成对过程装备的整体认识。2、概述传统的过程装备实训内容及其发展历程和发展趋势。3、概述数值模拟、虚拟现实、梳理孪生等数字化技术及其在过程装备实训中的应用。

    第二周：实验设计及数据采集基础（5课时）

    主要内容：1、介绍实验设计相关知识，包括实验设计的基本原则、单因素实验设计方法和多因素实验设计方法；2、介绍数据采集相关知识，包括数据采集的基本原理、Arduino数据采集、树莓派数据采集、虚拟仪器数据采集。

    第三周：数据处理基础（5学时）

    主要内容：介绍数据处理相关知识，包括1、误差分析与处理；2、数据回归；3、机器学习的数据预处理。

    第四周：数据处理类和数值计算类软件基础（5课时）

    主要内容： 1、介绍数据处理类软件，包括Excel、Origin、Matlab、R语言等，通过实例应用讲述软件的具体使用方法。2、介绍数值计算软件，包括ANSYS和COMSOL，结合实际案例，介绍其计算流程和方法。

    第五周：虚拟仿真类和测试控制类软件基础（5课时）

    主要内容：1、介绍建模与虚拟仿真类软件，包括三维建模软件Solidworks和增强显示（AR）与虚拟现实（VR）引擎，结合实际案例，介绍其使用流程和方法； 2、介绍测试与控制类软件，包括虚拟仪器软件Labview和控制仿真软件matlab&amp;simulink，结合实际案例，介绍其使用流程和方法。

    第六周：压力容器实验的理论基础及其数值模拟（5课时）

    主要内容：1、介绍容器在内压载荷下的力学响应、失效过程及失效机理；2、介绍外压容器在外压载荷下的力学响应、失效过程及失效机理；3、以内压容器和外压容器失效为例，介绍利用ANSYS软件模拟容器的加载及失效过程，分析容器受载过程中的应力应变分布及演化过程，熟悉ANSYS在内压容器计算中的应用。

    第七周：内压容器的应力测试和塑性垮塌实验（5课时）

    主要内容：1、开展内压容器应力测试和塑性垮塌实验。2、通过实验掌握应变电测法测量应力的原理和方法，以及内压容器塑性垮塌过程中载荷和容器变化的关系曲线，并将测试结果与理论计算结果和数值计算结果进行对比。

    第八周：外压容器的屈曲失效实验（5课时）

    主要内容：1、开展外压容器的失稳失效实验。2、通过实验掌握容器失稳的原理，以及失稳压力的确定方法。

    第九周：流体增压机械实验基础及虚拟仿真（5课时）

    主要内容： 1、介绍流体增压机械的工作原理和结构特点，包括活塞式压缩机和离心泵的工作原理。2、利用虚拟仿真软件模拟活塞式压缩机和离心泵的建模，并进行虚拟实验。3、结合虚拟实验对实验进行优化设计。

    第十周：活塞式压缩机和离心泵实验操作（5课时）

    主要内容：1、活塞式压缩机示功图实验。2、活塞式压缩机性能调节实验。3、离心泵水力性能与汽蚀余量测试。4、离心泵运行调节实验。

    第十一周：离心泵组串并联性能实验操作（5学时）

    主要内容：1、离心泵组在串联和并联配置下的性能测试，2、如何通过实验来分析和比较不同配置下的流体动力学特性和系统效率。

    第十二周：计算机控制实验基础及操作（5课时）

    主要内容：1、工频信号数据采集实验。2、被控对象特性的实验，包括一阶系统被控对象特性实验和二阶系统被控对象特性实验。

    第十三周：反应釜温度控制实验（5课时）

    主要内容：1、反应釜温度控制系统的设计和运用。2、温度控制策略的评估和优化。3、使用传感器和自动化技术实现精确温度控制的方法。

    第十四周：机器学习基础（5学时）

    主要内容：1、机器学习的基本概念，包括监督学习、非监督学习、强化学习等。2、如何使用机器学习算法来处理和分析数据。3、如何将这些技术应用于过程装备的状态监测和智能识别。

    第十五周：过程装备状态智能识别实验（5课时）

    主要内容：1、介绍过程装备状态监测和智能识别的基础知识。2、实验操作智能识别系统，包括数据采集、特征提取和状态判断。3、利用数字化技术对过程装备的运行状态进行实时监测和故障诊断。

    第十六次：小结和复习（5课时）

    主要内容：本节对整个课程内容进行回顾，重点说明本课程的要点和难点，巩固讲授的知识内容，对过程装备数字化实训技术进行展望，回答同学提问。
