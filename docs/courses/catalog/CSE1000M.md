# 自动化导论

## 课程简介

??? abstract "展开查看"

    本课程是面向自动化专业或其它工科专业一、二年级本科生的导论性课程，目的是通过课程讲授和教学演示，使学生从低年级就能对自动化控制学科及其技术方法有初步的了解认识，进一步促使学生热爱本专业。课程主要内容包括：自动控制系统的基本概念、传感检测技术、过程控制系统与应用、智能工厂、机器人技术、数据分析、工控系统安全等。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本课程属专业导论课，其核心任务是使自动化专业低年级本科生了解专业培养方案与知识体系，同时提高对自动化专业的兴趣，强化后续学习的主动性。考试评分以课堂参与、课程报告撰写为主。

1. 总评成绩= 90%期末大作业成绩 + 10%平时成绩。

2. 平时成绩由到课情况、课堂提问/测试等构成。

3. 期末大作业成绩根据学生提交的课程报告情况评定。要求每位同学结合自己的兴趣，从上课老师提供的主题清单中选择某一主题撰写课程报告，课程报告字数应不少于3000字。

### 课程大纲

??? abstract "展开查看"

    第一次：自动控制系统的概念与组成及应用实例 2学时

    结合日常生活、工农业生产与军事领域，了解自动化技术的起源、发展历程与广泛的应用领域；简单介绍自动化系统的分类，重点介绍一类典型的具有“反馈”功能的高端控制系统，并详细说明反馈控制系统的主要组成部分；最后结合现代工业与航天航空领域，举例说明自动控制系统应用的广泛性，并揭示控制系统对社会发展所起的关键作用。

    第二次：传感与检测技术 2学时

    结合日常生活，介绍传感技术的发展历程与广泛的应用领域；简单介绍传感技术在自动化系统的关键作用，介绍传感器的分类、内部结构与主要组成部分；最后结合现代工业领域，举例说明传感器应用的广泛性。

    第三次：过程控制系统与应用 2学时

    结合流程工业领域，介绍过程控制技术的起源、发展历程与广泛的应用领域；重点结合聚热式太阳能发电站，说明过程控制系统的主要组成部分以及所涉及的关键技术；最后概要介绍自动化专业的课程体系与本科培养方案。

    第四次：流程工业智能工厂 2学时

    从工业互联网平台与体系架构的发展与现状、流程工业智能工厂的特征与案例、新一代智能工厂初步探索等三个方面展开，阐述如何实现工厂从数字化与网络化到面向高质量发展的智能化的发展思路与关键技术等。

    第五次：机器人的前生、今世与未来 2学时

    简单介绍机器人技术的起源与发展历程；以自主开发研制的乒乓球对打机器人为例，详细说明机器人系统的主要组成部分，揭示自主开发机器人需要掌握的关键技术；最后举例说明机器人技术的广泛应用前景。

    第六次：从飞翔生物到飞行机器 2学时

    简单介绍飞行器的起源与发展历程，重点介绍飞行器的基本工作原理与自动控制技术，并结合自主开发的“无人机”，说明涉及系统性能的关键控制技术。

    第七次：数据魔法解析与智慧世界初探 2学时

    结合日益流行的“大数据分析”技术，简单介绍大数据分析的基本原理，重点介绍大数据分析解析所涉及的数学方法，包括概率论、应用统计、数据挖掘等；最后结合日常生活，举例说明数据解析的应用价值。

    第八次：新一代工业互联网信息系统安全 2学时

    结合我国工业互联网实际情况，介绍工业互联网的概念、重要性和特点，阐述工业物联网信息系统安全的必要性与重大意义，提出解决工业互联网系统安全的关键科学技术问题，介绍目前工业互联网信息系统安全研究的发展历程与现有技术水平；最后结合实例，举例说明工业互联网信息系统安全的应用前景。
