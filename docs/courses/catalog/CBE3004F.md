# 化工原理及实验

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 化工原理及实验<br><small>CBE3004F</small> | 储能普通班 · 26级<br>**专业基础必修** |

## 课程简介

??? abstract "展开查看"

    《化工原理及实验》主要理论内容共7章，分别为第1章流体力学基础，第2章流体输送机械，第5章热量传递基础，第6章传热过程计算与换热器，第8章质量传递基础，第9章气体吸收及第10章蒸馏；主要实验共3个，分别为流体力学综合实验-离心泵特性曲线测定实验，对流传热系数测定实验及筛板蒸馏塔实验。通过该课程的学习，使学生掌握工业过程中常用的单元操作的基本原理及其相关的理论基础，并能进行相应的单元操作工艺计算和设计。课程内容具有较鲜明的时代特征，在学科交叉的教学方面有显著特色。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考试方式：期末开卷。

评价方法：加强过程性考核，强化考核学生的主动参与度，增加考核学生对学科知识和课程思政有机结合的理解深度。

成绩构成比例：

主动参与20%，课堂讨论、习题、现场答疑和讨论；

阶段测试15%，在线测试，随堂阶段测验；

实践环节15%，课外拓展性学习和课程思政研习，单元操作实验；

期末开卷考试50%。
