# 智能控制技术及应用

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 智能控制技术及应用<br><small>EE3366M</small> | 车辆 · 26级<br>**专业选修** |

## 课程简介

??? abstract "展开查看"

    本课程讲述智能控制学科中的模糊控制理论、神经网络控制理论及预测控制理论及其应用。主要内容包括几种控制技术的基本概念、典型控制器的设计分析方法及其在电气工程及其自动化领域中的实际应用。通过对本课程的学习将使同学对智能控制的基本原理和应用有初步的了解，为今后对智能控制理论的进一步研究及应用打下基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    第一周 课程介绍及模糊数学基础

    理论讲授（4课时）

    介绍控制理论的产生及发展，智能控制的发展，传统控制和智能控制的关系，智能控制的类型，本课程研究的主要内容，神经网络的基本概念。介绍模糊逻辑控制的数学基础，介绍模糊逻辑理论的基本概念，包括模糊集合及其运算。

    第二周 模糊逻辑关系与模糊推理

    理论讲授（4课时）

    介绍模糊关系与模糊逻辑，介绍模糊逻辑理论的基本概念，模糊关系及其合成，模糊向量及其运算，模糊逻辑规则和模糊逻辑推理。介绍模糊逻辑控制系统的基本结构，包括模糊控制系统的组成，模糊控制器的基本结构，模糊控制器的维数，模糊控制中的几个基本运算操作。模糊逻辑控制系统的基本原理，包含模糊化运算，数据库，规则库，模糊推理，清晰化计算。

    第三周 模糊工具箱与模糊PID

    理论讲授（4课时）

    MATLAB模糊逻辑工具箱函数，MATLAB模糊逻辑工具箱简介，包括模糊逻辑工具箱的功能特点，模糊推理系统的基本类型，模糊逻辑系统的构成，利用模糊逻辑工具箱建立模糊推理系统，模糊推理系统的建立、修改与存储管理，模糊语言变量及其语言值，模糊语言变量的隶属函数，模糊规则的建立与修改，模糊推理计算与去模糊化。介绍离散论域的模糊控制系统的设计和具有PID功能的模糊控制器，1.引入积分因子的模糊PID控制器；2.FUZZY-PID混合控制；3.模糊自适应整定PID控制。

    第四周 自适应模糊控制器

    理论讲授（4课时）

    介绍基于模糊控制规则调整的模糊控制，基于比例因子调整的模糊控制器，基于论域调整的模糊控制器和基于隶属度函数调整的模糊控制器

    第五周 经网络理论

    理论讲授（4课时）

    介绍典型神经网络的模型，包含MP模型，感知机神经网络，应线性神经网络，BP神经网络。

    第六周 神经网络与神经网络控制理论

    理论讲授（4课时）

    介绍BP神经网络的系数调整规则和Mablab实现，介绍典型神经网络的模型，包含径向基神经网络，竞争学习神经网络，学习向量量化（LVQ）神经网络，Elman神经网络，Hopfield神经网络，Boltzmann神经网络。

    第七周 神经网络工具箱

    理论讲授（4课时）

    神经网络工具箱函数, 介绍神经网络工具箱中的通用函数，感知机，，线性神经网络，BP神经网络，径向基神经网络，自组织神经网络，学习向量量化（LVQ）神经网络，Elman神经网络，Hopfield等神经网络的MATLAB函数，利用Demos演示神经网络的建立，以及MATLAB神经网络工具箱的图形用户界面，介绍基于Simulink的神经网络模块，包括模块的设置和模块的生成，基于Simulink的三种典型神经网络控制系统，包括神经网络模型预测控制，反馈线性化控制，和模型参考控制。

    第八周 工程应用与课程总结

    理论讲授（4课时）

    介绍智能控制技术在工程前沿中应用情况，进行课程总结与复习。
