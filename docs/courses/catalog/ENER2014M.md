# 电化学储能基础

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 电化学储能基础<br><small>ENER2014M</small> | 储能普通班 · 26级<br>**专业必修** |

## 课程简介

??? abstract "展开查看"

    本课程主要内容包括：电化学基础理论（电化学热力学、电极过程动力学）、电化学研究方法（电化学阻抗谱、循环伏安法等）、各类储能电池的工作原理与技术特性（超级电容器、锂离子电池、新型储能电池、固态电池等）。课程聚焦新能源革命带来的能源结构快速调整，储能技术作为新能源发展的核心支撑，在电动汽车、新能源与智能电网、AI数据中心供电系统等场景中展露出巨大的发展潜力。本课程旨在拓展学生的电化学基础知识面，加深其对各类电化学储能系统工作原理的理解，提高对未来储能技术发展趋势的分析判断能力，为从事人工智能、新能源与智能电网、汽车动力系统等领域的研究和开发提供专业基础知识

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    第一周：绪论：电化学储能技术概述

    储能技术的战略意义；储能方式分类（物理储能、化学储能、电磁储能、热储能）；电化学储能在新能源体系中的定位；电化学储能发展简史与未来趋势，其中以伏打电堆、超级电容器、二次电池为例介绍电化学储能的基本原理和应用。

    第二周：电化学基础I：热力学

    电解质溶液的基本性质；电化学势与电极电势；能斯特方程及其应用；标准电极电势与标准电池电动势；参比电极的类型与选择。

    第三周：电化学基础II：界面与双电层

    电极-溶液界面的结构；双电层理论模型（Helmholtz模型、Gouy-Chapman模型、Stern模型）；双电层的热力学与自由能；电毛细现象。

    第四周：电化学基础III：电极过程动力学

    导法拉第过程与非法拉第过程；电极反应速率与活化能；Butler-Volmer方程及其简化形式；交换电流密度与过电位；塔菲尔方程；电化学极化与浓差极化。

    第五周：电化学研究方法（瞬态和稳态）

    电化学测试体系与基本方法：介绍三电极体系的组成与作用，包括工作电极、参比电极和对电极，讲解电化学工作站的基本功能及实验规范。在此基础上，系统介绍稳态与瞬态电化学测试方法，包括线性扫描伏安法（LSV）、循环伏安法（CV）、计时电流法（CA）和计时电位法（CP），分析电极过程中的电荷转移与传质行为。重点讲授极化曲线、塔菲尔分析及Cottrell方程等基本理论，掌握扩散系数、交换电流密度等动力学参数的获取方法，为后续储能器件性能分析奠定基础。

    第六周：电化学阻抗谱与等效电路

    电化学阻抗谱（Electrochemical Impedance Spectroscopy，EIS）原理与等效电路拟合：EIS是一种获取体系阻抗随频率变化的频谱分析技术。重点讲解EIS的基本测试原理，如何通过构建等效电路将电化学体系的复杂行为转化为可量化的阻抗参数，进而反映体系内部的电荷转移、物质扩散、界面反应等过程。

    第七周：超级电容器I基本原理

    双电层储能机制与器件基础：介绍电容器、超级电容器和电池三类储能器件的特点与区别，重点讲解电化学双电层电容（EDLC）的储能原理。从Helmholtz模型、Gouy-Chapman模型和Stern模型出发，阐述电极/电解液界面的双电层结构及电容形成机制。分析活性炭、石墨烯、碳纳米管等典型碳材料的结构特点及储能行为，并介绍水系、有机系和离子液体电解液的性能差异，掌握比电容、能量密度、功率密度和循环寿命等关键评价指标。

    第八周：锂离子电池

    锂离子电池工作原理与关键材料：介绍锂离子电池的发展历程及“摇椅电池”工作原理，重点讲解锂离子在正负极材料中的嵌入与脱嵌过程。系统分析层状氧化物、尖晶石、橄榄石等正极材料以及石墨、硅基等负极材料的结构与性能特点，阐述电解液和隔膜在电池中的作用。结合充放电曲线和循环性能测试，分析电池容量、倍率性能和衰减机制，并介绍锂离子电池在新能源汽车和储能电站中的典型应用。

    第九周：超级电容器II赝电容与混合电容

    法拉第储能机制与混合储能体系：在双电层电容基础上，介绍赝电容储能机理，重点讲解过渡金属氧化物、氢氧化物及导电聚合物中的快速表面氧化还原反应。分析赝电容与电池型行为的区别及判据，利用循环伏安和恒流充放电曲线识别不同储能机制。进一步介绍非对称超级电容器和锂离子电容器等混合储能体系，探讨其兼具高功率密度和高能量密度的设计思想与应用前景。

    第十周：超级电容器III多孔电极理论

    多孔电极结构与离子输运理论：介绍超级电容器电极材料中的微孔、介孔和大孔结构及其功能分工，分析孔径分布、比表面积和孔连通性对储能性能的影响。重点讲授多孔电极中的离子扩散、电荷传递和电场分布规律，引入传输线模型和多孔电极理论，建立材料结构与器件性能之间的关联。结合典型碳材料案例，讨论高功率与高能量储能器件的结构设计原则。

    第十一周：新型电化学储能电池体系

    介绍锂离子电池之外的重要二次电池体系，包括钠离子电池、钾离子电池、锂硫电池、金属空气电池及液流电池等。重点分析不同体系的工作原理、关键材料和技术特点，比较其能量密度、功率密度、安全性、资源成本及产业化现状。通过典型案例说明新型电池体系在大规模储能、电动交通和特殊应用场景中的发展潜力与技术挑战。。

    第十二周：固态电池

    固态电池原理与关键科学问题：介绍固态电池的发展背景及其在高能量密度和高安全性方面的优势。重点讲授氧化物、硫化物和聚合物固态电解质的离子传导机制与性能特点，分析固-固界面接触、界面阻抗和锂枝晶生长等关键问题。结合全固态锂电池结构设计，讨论当前研究热点及产业化进展，理解固态电池未来的发展方向。

    第十三周：电化学阻抗谱应用

    电化学阻抗谱原理与储能器件分析：介绍交流阻抗测试原理及频率响应分析方法，理解Nyquist图和Bode图的物理意义。讲解电解液电阻、电荷转移阻抗、双电层电容和扩散阻抗等典型电化学过程的阻抗特征，掌握Randles等效电路模型的建立与拟合方法。结合超级电容器和锂离子电池实例，分析阻抗谱在界面研究、性能衰减和失效机理分析中的应用。

    第十四周：原位电化学表征技术

    电化学储能过程的原位与实时表征：介绍原位表征技术在电化学储能研究中的重要作用，重点讲解原位电化学石英晶体微天平（EQCM）、原位核磁共振波谱（NMR）、原位X射线衍射（XRD）、原位透射电子显微镜（TEM）基本原理。分析储能材料在充放电过程中结构、价态和界面演化行为，理解原位表征在揭示储能机制和指导材料设计中的价值。

    第十五周：前沿专题与学生汇报

    电化学储能前沿进展：围绕当前电化学储能领域的重要研究方向开展专题讨论，包括固态电池、钠离子电池、新型超级电容器及人工智能辅助材料设计等前沿内容。组织学生进行文献调研与专题汇报，培养自主学习、文献阅读和学术表达能力。通过课程总结梳理电化学储能体系的基本原理、研究方法及未来发展趋势，建立完整的知识框架。

    第十六周：小结和复习

    对整个课程内容进行回顾和总结，重点说明课程的要点，巩固讲授的知识内容，回答同学提问。
