# 新能源动力系统能效管理与储能安全

## 课程信息 {#course-information}

## 课程简介

??? abstract "展开查看"

    新能源动力系统能效管理与储能安全主要介绍以电化学储能为核心的新能源动力系统（纯电动、混合动力、燃料电池及多能融合动力系统）的能量流分析与能效管理方法，以及储能系统热管理与安全设计的基本理论、关键技术和工程实践，是卓越工程师班“先进能源装备”项目式学习模块的一门专业必修课程。课程内容涉及工程热力学、传热学、电化学、控制理论、电气工程及车辆工程等相关基础知识，主要包括新能源动力系统概述、动力系统能量流与能效分析、面向控制的建模与仿真、基于规则与基于优化的能量管理策略、储能系统状态估计与寿命管理、储能系统热管理、电化学储能失效机理与热失控、储能系统本征安全与主被动安全设计、储能安全标准法规与测试评价、大规模储能电站安全与智能运维等内容。通过本课程的项目式学习，学生能够掌握新能源动力系统能效管理与储能安全的基本原理和关键技术，具备运用现代仿真工具解决动力系统能效与储能安全复杂工程问题的初步能力，了解相关产业的发展趋势与标准法规体系。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
