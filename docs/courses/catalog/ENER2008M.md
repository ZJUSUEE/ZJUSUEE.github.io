# 虚拟制冷教学实践

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 虚拟制冷教学实践<br><small>ENER2008M</small> | 低温 · 25级及以前、26级<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    本课程包括线上实践教学和线下实践教学两个部分。采用制冷领域虚拟实践教学系统展示典型制冷装置的复杂原理和运行调节过程。有机结合多媒体技术和网络技术，营造多样化的学习和演示环境，使得学生能够对课程内容有更形象和深刻的了解。本系统共分八个部分：制冷的方法、电冰箱、空调器、冷库、中央空调、小型低温制冷机、低温贮运装置和换热器。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

期末网上考试占50％，课程作业占20％，实习总结占30％

### 课程大纲

??? abstract "展开查看"

    第1次课 虚拟教学制冷实践仿真操作与学习 + 虚拟教学制冷实践讲座：课程导论

    理论讲授、讨论（6课时）

    主要内容：

    （1）了解制冷与低温专业特点、课程设置。

    （2）课程简介 -- 制冷原理、低温原理。

    （3）课程定位，课程教学的方式（网上学习+线下实训）、历年的课程回顾。

    （4）课程内容和要求—网上学习+课堂讲解+动手实践+企业参观。

    （5）思考如何将AI技术与基础知识如何更好地结合。

    第2次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：电冰箱和冷库

    理论讲授、讨论（6课时）

    主要内容：

    （1） 冰箱的发展历史: 回顾世界冰箱的起源和发展情况，讨论我国冰箱的引进和发展情况。

    （2） 冰箱的种类: 详细介绍冰箱的基本分类，包括冷藏箱与冷藏冷冻箱，以及不同的制冷方式，如压缩制冷与吸收制冷，并介绍相关工质、特点和应用。

    （3） 冰箱的组成: 介绍压缩机、冷凝器、蒸发器与毛细管等主要部件，简介蒸气压缩式制冷循环和吸收制冷循环。

    （4） 冰箱的命名: 详细介绍家用冰箱的命名方式，包括气候类型、容量、频率等，了解各自属性及应用场景。

    第3次课 虚拟教学制冷实践+拆装培训（实验室现场操作）

    理论讲授、实践、讨论（6课时）

    主要内容：

    （1）制冷虚拟教学实践线上系统的操作及对于制冷基础知识的学习。

    （2）实验室安全教育。

    （3）制冷系统的基本构成及工作原理。

    （4）制冷系统每一部件及其作用。

    （5）动画演示冰箱与空调器的结构及拆解过程及安装过程。

    （6）动手操作---管道的连接、弯管、扩管、控制系统等。

    第4次课 虚拟教学制冷实践+电冰箱拆装（实验室现场操作，分8组，共2天）

    理论讲授、讨论（6课时）

    主要内容：（1，2，3，4组）

    （1）介绍冰箱的组成: 结合实物介绍压缩机、冷凝器、蒸发器与毛细管等主要部件，加深学生对蒸气压缩制冷循环的理解。

    （2）冰箱的拆解: 指导学生手动拆解冰箱制冷循环回路中的测试管道，同步讲解管道内部工质的流动方向和特性。

    （3） 冰箱的组装: 指导学生手动制作铜管的喇叭口，并将制作好的管道重新连接到测试回路中，检查系统密封性完好后，通过电气控制开关切换压缩机至工作状态。提高学生动手能力，并认识到实际应用时管道连接处的密封对整个制冷系统的重要性。

    （4） 冰箱制冷性能检测: 通过观察蒸发器和管道凝结的水雾，检测冰箱制冷效果，让学生们深入理解冰箱的工作机理。

    第5次课 虚拟教学制冷实践+电冰箱拆装（实验室现场操作，分8组，共2天）

    理论讲授、测试（6课时）

    主要内容：（5，6，7，8组）

    （1）介绍冰箱的组成: 结合实物介绍压缩机、冷凝器、蒸发器与毛细管等主要部件，加深学生对蒸气压缩制冷循环的理解。

    （2）冰箱的拆解: 指导学生手动拆解冰箱制冷循环回路中的测试管道，同步讲解管道内部工质的流动方向和特性。

    （3） 冰箱的组装: 指导学生手动制作铜管的喇叭口，并将制作好的管道重新连接到测试回路中，检查系统密封性完好后，通过电气控制开关切换压缩机至工作状态。提高学生动手能力，并认识到实际应用时管道连接处的密封对整个制冷系统的重要性。

    （4） 冰箱制冷性能检测: 通过观察蒸发器和管道凝结的水雾，检测冰箱制冷效果，让学生们深入理解冰箱的工作机理。

    第6次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：空调器和中央空调

    理论讲授、测试（6课时）

    主要内容：

    （1） 空调器和中央空调发展: 回顾世界空调起源和发展情况，讨论我国空调最早的应用场景及发展情况。

    （2） 空调的种类: 详细介绍空调基本分类压缩空调、吸收制冷与吸附空调，介绍相关工质、特点和应用。

    （3） 空调的组成: 介绍压缩机、冷凝器、蒸发器与热力膨胀阀等主要部件，简介蒸气压缩式制冷循环和吸收吸附制冷循环。

    （4） 空调的命名: 详细介绍空调的命名方式，包括气候类型、容量、频率等，了解各自属性及应用场景。

    第7次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：制冷的方法

    理论讲授、测试（6课时）

    主要内容：

    （1）冷的简史: 课堂讨论在没有蒸汽机和电力时有哪些制冷的方法，讲述古代人类如何利用自然条件获得低于环境温度和夏季制冰。

    （2）相变制冷: 详细介绍基本原理，讲解历史上最早的制冷循环，介绍相关工质、特点和应用。

    （3）气体膨胀制冷: 详细介绍绝热放气制冷的三种方式，介绍历史上最早的空气压缩制冷机，简介蒸气压缩式制冷循环和四大部件。

    （4）其他制冷方法: 简要介绍采用其他原理的制冷方式，包括磁卡制冷、电卡制冷、弹卡制冷、涡流管制冷、天空辐射制冷、激光制冷等，了解各自特点及应用场景。

    第8次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：换热器

    理论讲授、讨论（6课时）

    主要内容：

    （1）换热器概述: 简要介绍换热器的基本原理和主要功能，重点描述常见制冷场合如冰箱空调中换热器的重要作用。

    （2）管式换热器: 概述翅片管式换热器、管壳式换热器、绕管式换热器的功能特点和应用场合。

    （3）板式换热器: 概述板式换热器、板翅式换热器等的功能特点和应用场合，分析其封装方式和优缺点。

    第9次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：小型低温制冷机

    理论讲授、讨论（6课时）

    主要内容：

    （1）低温制冷技术的应用需求与分类，小型低温制冷机的概念，类型与基本特点；

    （2）JT制冷机与回热式制冷机的概念与结构特点，间壁式换热器与交变流回热器的换热特性与性能对比；（3）回热式制冷机的分类与概念，回热器的填料类型与特点，回热式循环基本原理，以及不同回热式制冷机的发展简介。

    第10次课 虚拟教学制冷实践+空调器拆装（实验室现场操作，分8组，共2天）

    理论、实践、讨论（6课时）

    主要内容：（1，2，3，4组）

    （1）空调器的组成及工作原理：通过现场实际的空调系统详细讲解空调器的组成及工作原理。

    （2）拆解空调器，然后重新制作管道连接及控制器的接线，并进行整体系统的安装。

    （3）系统密封性检测直到系统无泄露，充注一定量的制冷剂到系统（了解充注过程，在充注过程中开机），空调系统的正常运行及记录过程。

    （4）空调系统运行后关闭过程的操作直到系统安全关闭，关闭总电源，收拾工具整理到工具箱。

    第11次课 虚拟教学制冷实践+空调器拆装（实验室现场操作，分8组，共2天）

    理论讲授、讨论（6课时）

    主要内容：（5，6，7，8组）

    （1）空调器的组成及工作原理：通过现场实际的空调系统详细讲解空调器的组成及工作原理。

    （2）拆解空调器，然后重新制作管道连接及控制器的接线，并进行整体系统的安装。

    （3）系统密封性检测直到系统无泄露，充注一定量的制冷剂到系统（了解充注过程，在充注过程中开机），空调系统的正常运行及记录过程。

    （4）空调系统运行后关闭过程的操作直到系统安全关闭，关闭总电源，收拾工具整理到工具箱。

    第12次课 虚拟教学制冷实践仿真操作与学习+ 虚拟教学制冷实践讲座：低温储运装置

    理论讲授、讨论（10课时）

    主要内容：

    （1）低温流体的分类与储运需求简介，低温储罐的基本概念。

    （2）低温储罐的材料，结构，绝热基本原理介绍，低温容器设计的基本步骤与原则。

    （3）LNG储罐需求与概念，液氢储罐发展现状与车载液氢储罐案例分享。

    第13次课 钱江压缩机公司参观

    理论讲授、讨论（4课时）

    主要内容：

    （1）讲解冰箱压缩机的结构及工作原理及类型。

    （2）讲解生产压缩机的详细工艺流程、生产中所采用的先进技术对于压缩机产量的贡献。

    （3）压缩机生产车间的现场参观，进一步通过直观的方式了解压缩机的生产过程及生产过程中所使用的先进技术。

    （4）详细参观实验室，详细了解公司生产的压缩机在不同系统中的应用测试。

    第14次课 大金（中国）投资有限公司技术开发研究院参观

    理论讲授、讨论（8课时）

    主要内容：

    （1）讲解大金公司空调系统的发展及目前公司空调系统的种类及应用场景。

    （2）由企业技术人员带领师生们一同参观大金（中国）投资有限公司技术开发研究院实验室，了解产品研发中的关键流程。

    （3）进一步讨论当前制冷空调系统的发展前景及面临的主要挑战。

    第15次课 虚拟教学制冷实践仿真操作与学习+答疑

    理论讲授、讨论（6课时）

    主要内容：

    （1）课程内容总结：回顾前面课程的主要内容，帮助学生理清学习重点。

    （2）常见问题解答：解答学生在实习过程中遇到的常见问题和困惑。

    （3）知识点强化：针对学生的疑问进行详细讲解，确保学生对关键知识点有清晰的理解。

    第16次课 答疑

    理论讲授、讨论（6课时）

    主要内容：

    （1）实操问题解答：解答学生在实际操作或VR模拟中遇到的具体问题和挑战。

    （2）案例分析：讨论实际案例中的问题和解决方案，进一步加深学生对于制冷与低温专业的基础知识的掌握及实际操作能力。

    （3）学习反馈与建议：收集学生的反馈，提供针对性的建议，帮助他们进一步提升技能。

    （4）线上模考试测试。
