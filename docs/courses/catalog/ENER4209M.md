# 毕业设计（论文）

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |

25级及以前：ENER4209M，8学分；26级：ENER4209M1，6学分。

## 课程简介

??? abstract "展开查看"

    本课程是面向过程装备与控制专业学生开设的一门实践课程，在专业课程体系中居重要地位。通过本课程的教学，培养学生综合运用所学的专业基本理论、基本知识进行独立分析、解决实际问题的能力，培养和提高学生的创新意识和实践能力，使学生获得科学研究的基础训练，为他们将来从事本专业的工作和进一步学习打下良好的基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    第一周：论文选题

    课外学习与作业要求：分析报告

    第二周：文献检索

    课外学习与作业要求：文献收集

    第三-四周：文献综述

    课外学习与作业要求：对文献进行评述。

    第五周：方案设计

    课外学习与作业要求：方案、路线、可行性分析。

    第六周：报告

    撰写文献综述报告；翻译外文；撰写开题报告，开题答辩

    第七周-十二周：毕业设计具体方案实现（计算、仿真、样机设计、实验研究）等

    课外学习与作业要求：报告、图纸、样机。

    第十三周-十四周：毕业论文撰写、毕业答辩

    毕业论文。
