# 过程装备安全与防腐

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 过程装备安全与防腐<br><small>ENER3219M</small> | 过控 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程主要包括化工安全技术、腐蚀原理与防护技术和思政素质提升。通过本课程的学习，使学生了解化工安全技术的基本内容、防火防爆、化工单元操作、压力容器等安全技术以及腐蚀的基本原理、破坏形式、材料选用及防腐结构设计等知识，掌握化工事故处理的基本方法和化工设备防腐蚀设计的技术要求，为今后走向工作岗位奠定一定基础。同时结合安全知识，与国家和社会稳定、工业生产健康发展相融合，强调遵纪守法，加强“四个自信””，勇于创新，实现课程教学知识传授、能力培养、素质提升、人格塑造相统一。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本门课程的评分分为3个部分，每个部分分数分配如下：课堂发言讨论20％、课后作业20%、期末闭卷考试60%。

### 课程大纲

??? abstract "展开查看"

    第一次：腐蚀与防护技术的绪论

    主要内容：解释腐蚀的定义，指出腐蚀的危害性（介绍几起近年来国内外因腐蚀造成的失效破坏典型案例），列举目前我国有关腐蚀的标准体系；介绍全面腐蚀和局部腐蚀程度的评介方法，使学生掌握中、美、日三国金属材料耐腐蚀等级的划分标准；讲述按原理、破坏形式和环境等原则进行腐蚀分类的方法以及影响腐蚀的内在因素和外在因素。使学生对腐蚀有初步的认识和了解。

    阅读材料：王宽福，《腐蚀原理与防护技术》，第一章，浙江大学出版社，1995年。

    作业题：查阅1~2个腐蚀破坏的工程案例，并了解其破坏的基本原因。

    第二次：腐蚀的基本原理

    主要内容：讲述物理腐蚀的基本原理（液态金属和熔融盐的概念、金属在液态金属中的腐蚀机理、金属在熔融盐中的腐蚀机理）、化学腐蚀的基本原理（以最为普遍的金属在高温气体中的氧化为对象，简要阐述化学腐蚀的基本原理和规律以及几种常见的气体腐蚀形式和防止的方法）、电化学腐蚀的基本原理（金属的电极电位、腐蚀电池、电化学腐蚀的热力学、电化学腐蚀过程的动力学、金属的钝化机理）。通过对腐蚀原理的研究，可使学生了解腐蚀产生的原理及其影响因素，从而更合理地选用材料和运用防腐蚀措施，发展更有效的防腐方法。

    阅读材料：王宽福，《腐蚀原理与防护技术》，第二章，浙江大学出版社，1995。

    作业题：（1）防止气体腐蚀的方法。（2）什么是金属的电动序？它有何作用？

    第三次：化工设备常用耐蚀材料及其使用原则

    主要内容：讲述主要金属元素对防腐蚀的作用，重点介绍化工设备常用的金属材料（碳钢、低合金钢、不锈钢、有色金属及其合金）的分类、牌号、特性及使用要求，使学生全面了解耐腐蚀材料的性能及适用条件。

    阅读材料：（1）何业东，《材料腐蚀与防护概论》，机械工业出版社，2005年。（2）王宽福，《腐蚀原理与防护技术》，第四章，浙江大学出版社，1995。

    第四次：压力容器材料使用原则

    主要内容：讲解压力容器材料的使用规定和选材原则，重点讲述关于“选用国外钢材”的规定、国外相应压力容器规范规定的钢材牌号介绍、关于“材料代用”的规定、压力容器钢板使用规定、压力容器选材原则，使学生全面了解应用于压力容器材料的特殊要求。

    阅读材料：（1）TSG R0004-2009《固定式压力容器安全技术监察规程》，国家质检总局，2009。（2）GB150-2010《固定式压力容器》，全国锅炉压力容器标准化技术委员会，2010

    讨论题：高温高速染色机爆炸原因分析。

    第五次：化工设备腐蚀破坏的基本形式（一）

    主要内容：讲述均匀腐蚀、电偶腐蚀、缝隙腐蚀、点蚀、晶间腐蚀、选择性腐蚀、磨损腐蚀灯破坏形式的形成机理、影响因素、破坏特点和预防措施。使学生能根据腐蚀破坏的特点判断腐蚀破坏的形式，并能解释其形成机理，提出相应的预防措施。

    阅读材料：（1）何业东，《材料腐蚀与防护概论》，机械工业出版社，2005年。（2）王宽福，《腐蚀原理与防护技术》，第三章，浙江大学出版社，1995年。

    第六次：化工设备腐蚀破坏的基本形式（二）

    主要内容：讲述应力腐蚀、腐蚀疲劳、氢损伤等破坏形式的形成机理、影响因素、破坏特点和预防措施。使学生能根据腐蚀破坏的特点判断腐蚀破坏的形式，并能解释其形成机理，提出相应的预防措施。

    阅读材料：（1）何业东，《材料腐蚀与防护概论》，机械工业出版社，2005年。（2）王宽福，《腐蚀原理与防护技术》，第三章，浙江大学出版社，1995。

    作业题：（1）阐述应力腐蚀与腐蚀疲劳的区别。（2）阐述氢脆与氢侵蚀的区别。

    第七次：化工设备防腐蚀设计（一）

    主要内容：化工设备防腐蚀设计主要包括选材、防腐蚀结构设计、防腐蚀强度设计、其它防腐蚀设计四个方面，本次课堂内容主要讲述选材时应考虑的主要因素、防腐蚀结构设计应遵循的基本原则，重点讲解结构形状、流体流动、应力、温度、几何布局对结构腐蚀的影响及防护对策，并针对管道系统、贮罐和容器分析其防腐蚀结构设计方法以及设备工艺设计和装配中的腐蚀控制。

    阅读材料：（1）章葆澄等，《防腐蚀设计与工程》，北京航空航天大学出版社，1998年。（2）王宽福，《腐蚀原理与防护技术》，第五章，浙江大学出版社，1995。

    作业题：查阅常见化工设备防腐蚀措施与方法的有关文献，并撰写综述报告。

    第八次：化工设备防腐蚀设计（二）

    主要内容：讲述防腐蚀强度设计（腐蚀余量、局部腐蚀的强度设计）以及在加工和施工处理时，可能会引起材料耐蚀强度特性的变化情况。在设计中，除结构和强度因素外，在选用材料时从经济考虑常常推荐各种防蚀保护措施，如使用防蚀涂料、电化学保护、缓蚀剂或其它工艺性防腐蚀措施等。

    阅读材料：（1）章葆澄等，《防腐蚀设计与工程》，北京航空航天大学出版社，1998年。（2）王宽福，《腐蚀原理与防护技术》，第五章，浙江大学出版社，1995。

    作业题：（同上）查阅常见化工设备防腐蚀措施与方法的有关文献，并撰写综述报告。

    第九次：防腐蚀技术（一）

    主要内容：讲述防腐蚀技术中的腐蚀环境的改善和缓蚀剂的应用知识（主要介绍改善腐蚀环境的十大要素、缓蚀剂的缓蚀原理和分类、缓剂蚀的使用条件及常用缓蚀剂的应用）和覆盖层保护法的分类方法以及电镀、化学镀、热镀、渗镀等常用表面处理方法的特点、原理、适用条件和预处理方法。

    阅读材料：王宽福，《腐蚀原理与防护技术》，第六章，浙江大学出版社，1995年。

    第十次：防腐蚀技术（一）

    主要内容：讲述电化学保护方法，重点介绍阴极保护（外加电流阴极保护和牺牲阳极保护）的基本原理、主要设计参数、阳极材料要求、应用场合和阳极保护的基本原理、主要设计参数、应用条件以及两种保护方法的比较。列举几个工程上典型的防腐蚀结构体系展开讨论。

    阅读材料：王宽福，《腐蚀原理与防护技术》，第六章，浙江大学出版社，1995。

    作业题：查找1~2个典型工程结构的防腐蚀体系。

    第十一次：化工安全技术绪论

    主要内容：讲述化工安全技术的重要性及与国家和社会稳定、国民经济健康发展的关系，强调遵纪守法，加强“四个自信”，勇于创新；现代化工生产的特点、安全生产在化工生产中的地位、安全技术的基本内容、安全技术标准规范、化工安全事故原因分类，介绍几起国内外化工安全事故典型案例。

    阅读材料：（1）金志江，《化工安全技术概论》，自编教学参考书，1997年。（2）易俊等，《化工生产过程安全技术》，中国劳动社会保障出版社，2010。

    第十二次：化学危险物质

    主要内容：介绍化学危险物质的分类、贮存运输及包装、处理的要求，重点讲述爆炸性物质、氧化剂、压缩气体和液化气体、自燃物质、遇水燃烧物质、易燃液体、易燃固体、毒害物质、腐蚀性物质、放射性物质等危险物质的特性。

    阅读材料：（1）金志江，《化工安全技术概论》，自编教学参考书，1997年。（2）易俊等，《化工生产过程安全技术》，中国劳动社会保障出版社，2010。

    作业题：阐述放射性物质的危害性及其预防方法。

    第十三次：燃烧与爆炸及防火防爆技术

    主要内容：讲述燃烧及燃烧条件、燃烧过程、燃烧形式及种类、燃烧理论、爆炸及其种类、爆炸破坏的主要形式、爆炸极限及其影响因素、粉尘爆炸的特性及影响因素以及相关的防火防爆技术。 阅读材料：（1）金志江，《化工安全技术概论》，自编教学参考书，1997年。（2）张奇等，《燃烧与爆炸基础》，北京理工大学出版社，2007。

    作业题：阐述压力容器的防爆抑爆方法。

    第十四次：化工单元操作安全技术

    主要内容：讲述物料输送、干燥、蒸发、蒸馏、冷却、冷凝、冷冻、筛分、过滤、粉碎、混合等单元操作过程的特点及其安全操作技术要求，使学生掌握化工单元操作的安全技术。

    阅读材料：（1）申奕，《化工单元操作技术》，天津大学出版社，2009年。（2）金志江，《化工安全技术概论》，自编教学参考书，1997。

    作业题：查阅化工单元操作过程的典型案例，介绍其应用、生产原理、设备结构、操作方法及设备使用维护要求。

    第十五次：压力容器安全技术

    主要内容：讲述压力容器基础知识、安全性能及安全装置、压力容器定期检验及安全运行管理、压力容器事故危害与事故分析。理论联系实际，结合国内外发生的大量压力容器事故案例，系统地阐述了压力容器发生各类事故的基本原因，并就压力容器的设计、制造、运行和检验等各个环节提出了防止事故发生所应采取的对策和具体措施。

    阅读材料：（1）刘道华，《压力容器安全技术》，中国石化出版社，2009年。（2）金志江，《化工安全技术概论》，自编教学参考书，1997。

    作业题：查阅1~2个压力容器事故案例并分析其破坏原因。

    第十六次：总结与复习

    对整个课程内容进行回顾总结，重点说明课程的要点并回答同学提问。
