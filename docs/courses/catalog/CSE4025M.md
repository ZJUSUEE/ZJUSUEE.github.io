# 人工智能大模型技术及应用

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 人工智能大模型技术及应用<br><small>CSE4025M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    本课程是专为控制科学与工程、信息科学及其他相关专业本科生设计的一门专业选修课，旨在深入探索人工智能领域的前沿技术——大模型技术。通过系统学习与实践操作，学生将全面掌握大模型的基本概念、核心原理、技术发展脉络及主要技术特点，同时培养在前沿科技领域进行独立研究与开发的能力。课程主要包括Transformer、Bert、GPT模型架构详解、大模型训练与系统挑战、优化策略、大模型安全问题与隐私保护技术、应用分析与实践等模块，授课形式为线下授课。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

平时成绩（10%）：包括课堂出勤率、参与度、上课提问与讨论表现等。

实验操作（60%）：包括个人实验课原始代码、运行结果、撰写报告、项目展示，从而评估实践技能。

课程论文/大作业（30%）：包括完成课程项目大作业，展现创新思维。
