## 课程简介

??? abstract "展开查看"

    本课程的基本内容为依据汽轮机设计的原始资料进行N125-13.24/535/535中间再热凝汽式汽轮机高压缸热力设计，本课程是《透平机械原理》等课程的后续课程，是热能专业的主要的实践课之一。主要教学内容包括：依据原始资料确定汽轮机的进汽流量，进行额定负荷下汽轮机调节级的详细热力计算，喷嘴和动叶的结构设计，高压缸8个压力级的直径确定、焓降分配和详细热力计算，绘制汽轮机高压缸结构的剖面图，并编写课程设计说明书。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

课程设计答辩。

总评成绩= 35%设计图纸 + 35%计算说明书 + 30%答辩。

### 课程大纲

??? abstract "展开查看"

    学生课外事先预习和回顾透平机械原理课程内容，预习汽轮机课程设计参考资料，了解汽轮机设计的原理和设计流程、包括汽轮机各种零部件的主要结构等基础知识。

    1．布置设计任务书，明确设计任务、热力设计计算步骤 1.5天

    明确汽轮机课程设计的目的、本次的设计任务（进行N125－13.24/535/535中间再热凝凝汽式汽轮机高压缸的热力设计）。汽轮机的已知原始参数、包括主蒸汽温度、压力、汽轮机设计转速、再热蒸汽压力和温度、排汽压力、整机功率、回热系统参数等。

    介绍汽轮机的热力设计计算步骤。包括全机拟定热力过程线、汽轮机进汽量的估算、高压缸的流量平衡计算、调节级的热力计算、压力级的热力计算、机组的功率和效率计算等。

    2．125MW转子实物观摩 0.5天

    紫金港校区的金工中心旁有125MW机组的转子实物，可参观整个转子的构造、包括高压缸、中压缸和低压缸的完整组成，喷嘴、动叶、隔板、围带的具体构造。

    3．设计全机热力过程拟定线 0.5天

    4．调节级的详细热力计算 3.5天

    （1）根据高压缸的流量平衡计算获得调节级的流量

    （2）计算调节级的平均直径

    （3）选取平均反动度计算喷嘴焓降

    （3）求喷嘴压比选喷嘴叶型

    （4）计算喷嘴出口速度、喷嘴出口面积、出口高度等参数

    （5）计算动叶焓降、动叶出口速度、动叶后蒸汽压力、动叶出口面积，进行动叶选型

    （6）校核动叶根部反动度

    （7）计算动叶出口角、余速损失

    （8）计算轮周焓降和轮周效率

    （9）计算各项损失、级有效焓降、级效率和级功率。

    （10）确定级后参数。

    5. 压力级的设计计算

    （1）计算第一压力级的平均直径

    （2）计算高压缸末级的平均直径

    （3）计算压力级级数

    （4）压力级焓降分配

    6．设计整机热力计算的程序框图 1天

    7．上机计算高压缸8个压力级 1天

    8．绘制汽轮机本体高压缸部分纵剖面图 3天

    绘制汽轮机高压缸部分的剖面图，包括喷嘴、动叶、汽缸、调节汽阀、主蒸汽管道、抽汽管道、测量原件等等。

    9．编写热力设计说明书 2天

    热力设计说明书包括设计任务书、详细的热力设计计算过程和步骤、中间的计算过程、高压缸各级的热力参数、设计总结、主要参考文献。

    10．课程设计答辩 1天

    学生提交热力设计说明书和图纸，接受老师3-5个问题的提问，进行回答。
