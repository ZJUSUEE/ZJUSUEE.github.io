## 课程简介

??? abstract "展开查看"

    本课程设置为跨大二、大三长学期一体化实践课程，面向高端制造、智能无人系统、未来能源三大国家战略方向，构建“基础实训—课题攻坚” 阶梯式企业实践体系。课程采用校内分层前置训练+企业长期驻场实践模式，前期完成产业认知、基础工程技能与小型课题训练，后期深度参与企业真实研发攻关项目，全程配备校企双导师。课程贯穿工程规范、安全保密、知识产权教育，循序渐进培养学生工程调研、方案设计、系统开发、迭代优化与成果交付能力，衔接项目式学习与本科毕业设计，搭建从课堂理论到产业真实工程场景的完整实践桥梁。同步融入卓工铸魂思政体系，引导学生走进产业一线感悟大国重器建设历程，树立科技报国使命担当。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

评分构成：全周期企业出勤、现场纪律与日常表现 20%；实践日志、调研记录、过程工单等全套过程材料 20%；两阶段工程任务完成度、交付成果质量 35%；综合实践报告、中期 + 期末成果答辩 25%。

学习建议：课前提前研读合作企业业务、产品技术路线，预习对应行业工程工具；主动向企业工程师请教实操难点，坚持每日复盘技术问题，形成个人工程笔记；合理规划长学期实践进度，预留充足时间开展数据整理、方案迭代、报告撰写；将实践课题与自身项目式学习、毕业设计方向深度结合，实现实践成果复用与持续深化。

### 课程大纲

??? abstract "展开查看"

    总学时：192 学时（校内分层前置训练 40 学时 + 企业两阶段驻场实践 128 学时 + 分阶段总结答辩 24 学时）

    第一阶段（大二长学期，96 学时）

    1–8 学时：实践动员、安全规范与保密培训

    内容：课程整体安排、三大产业企业介绍、安全操作、保密协议签署、长周期任务分解、分组与双导师对接；开展大国重器案例宣讲、行业领军工程师先进事迹学习、服务国家战略使命主题教育

    成果：安全承诺书、实践总任务书、分组名单、导师对接记录表

    9–24 学时：第一阶段校内前置训练

    内容：产业基础技术、工程现场调研方法、基础仿真与测试工具、实训报告撰写规范；同步讲解对应领域国产装备发展历程、自主创新典型案例

    成果：行业预习报告、现场调研提纲、工具操作训练记录

    25–64 学时：一期企业驻场基础实践

    内容：企业产线 / 研发中心熟悉、岗位观摩、基础数据采集、小型工程辅助任务、简易方案设计；现场讲解企业如何响应国家产业布局、一线员工攻坚克难真实故事

    成果：每日实践日志、现场照片与记录、小型实训任务初稿、阶段性数据汇总

    65–88 学时：一期成果整理与中期材料撰写

    内容：实训问题分析、方案微调、数据整理、中期实践报告初稿、汇报材料制作；引导结合实践经历反思产业短板，树立自主创新意识

    成果：中期实践报告、一期成果图纸 / 程序 / 测试数据、中期答辩 PPT

    89–96 学时：中期答辩与第一阶段考核复盘

    内容：小组中期成果汇报、校企导师点评、成绩阶段性评定、下一阶段任务调整优化；组织交流实践报国感悟，梳理后续实践攻坚目标

    成果：中期答辩记录、一期考核成绩单、二期实践调整方案

    第二阶段（大三长学期，96 学时）

    1–8 学时：二期实践任务交底、高阶工程规范培训

    内容：企业在研课题介绍、复杂工程测试标准、项目进度管理、企业技术文档规范；结合企业攻关任务解读国家产业政策，讲解工程人才助力突破关键核心技术、支撑产业自立自强的时代使命

    成果：二期专项任务书、课题需求确认单

    9–16 学时：第二阶段校内高阶前置训练

    内容：系统建模仿真、多目标优化、工程验收标准、专利与技术小结撰写；解读行业“卡脖子”技术现状、科研团队自主攻关典型事迹

    成果：课题技术调研综述、二期实施方案

    17–88 学时：二期企业深度驻场攻关实践

    内容：完整参与企业研发子课题、需求拆解、软硬件调试、多轮测试迭代、工程优化、阶段性交付验收；结合在研课题讲解该技术对国家产业链发展的重要价值

    成果：课题全流程工单、迭代方案、全套测试报告、可交付工程原型 / 程序 / 设计文件

    89–96 学时：期末综合答辩与课程总考核

    内容：全周期实践成果汇报、课题成果演示、双导师综合评审、总成绩核定、实践复盘归档；开展综合复盘，引导学生树立长期深耕实业、攻克技术难题的理想

    成果：完整综合实践报告、期末答辩 PPT、全套实践成果归档包、课程综合成绩单
