## 课程简介

??? abstract "展开查看"

    随着科技的飞速发展，人工智能已经成为当今社会的热门话题。特别是以GPT（生成式预训练模型）为代表的预训练大模型，其在各个领域的应用已经取得了巨大的成果。本课程为面向本科生的通识课程，旨在探讨新一代人工智能预预训练大模型的发展前沿、机遇与挑战。课程将聚焦于预训练大模型等人工智能前沿技术，内容包括：前沿和趋势、跨媒体智能与知识数据双轮驱动、GPT的前世今生、基础模型合成能力、预训练大模型人工智能治理、生成式人工智能前沿、预训练大模型与教育变革、预训练大模型的能力和使用等相关内容。课程采用研讨课模式，邀请领域专家分享、组织专题研讨、鼓励学生们积极参与讨论，探究如何在智能时代中发挥作用。课程还将提供相关背景知识和案例分析，帮助学生们深刻理解预训练大模型的基础知识和其在实践中的应用。本课程的预期学习目标包括但不限于：了解预训练大模型的基本原理、了解预训练大模型等人工智能技术的典型应用场景、了解预训练大模型对社会和产业的影响、学习如何使用预训练大模型相关工具进行学习和科研、掌握预训练大模型等人工智能前沿技术对所在学科发展的影响、掌握跟进人工智能发展前沿的方法。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

评分主要由三部分组成：

（1）出勤和课堂表现30%。包括：参与课堂讨论、提出问题、解答问题等。

（2）课后作业占30%。共6次，每次5%。包括：书面总结和反思、书面提问、书面解答问题等。

成绩均采用综合小组之间成绩互评、导师与助教、特邀专家评定相结合的方式。

（3）课程汇报占40%。包括：学生以小组方式完成课程汇报，集中展示、研讨，在第8周完成。

成绩均采用综合小组之间成绩互评、导师与助教、特邀专家评定相结合的方式。

    具体内容如下：

    第一周：预训练大模型大模型：前沿和趋势（孙凌云）

    课程内容：

    1. 介绍预训练大模型大模型的概念、特点和发展历程

    2. 介绍GPT系列模型的基本原理和特征

    3. 介绍头部公司的使命、愿景和研究方向

    4. 介绍预训练大模型的产业意义

    5. 介绍ChatGPT的功能、特色和典型应用

    研讨内容：

    1. 分析GPT系列模型在不同领域的应用效果和价值

    2. 讨论人工智能大模型对社会、经济、文化等方面的影响和意义

    3. 讨论人工智能大模型与大知识的关系

    第二周：预训练大模型的前世今生（汤斯亮）

    课程内容：

    1. 介绍神经网络与深度学习的发展简史

    2. 介绍语言模型与词嵌入的产生及其重要性

    3. 介绍BERT模型的提出与对NLP领域的巨大影响

    4. 介绍OpenAI的GPT大型语言模型的最新进展

    5. 介绍国内外预训练大模型的特征

    研讨内容：

    1. 分析预训练大模型的成就和不足

    2. 讨论预训练大模型的长期发展和数据依赖

    3. 讨论预训练大模型对于人工智能的长期影响

    第三周：基础模型的合成能力：涌现机理（特邀：吴飞 教授）

    课程内容：

    1. 介绍预训练大模型的涌现现象

    2. 介绍预训练大模型的概念、特点和分类

    3. 介绍涌现机理的概念、类型和原理

    4. 介绍基础模型合成能力与涌现机理的关系和作用

    5. 介绍预训练大模型中涌现机理的研究热点

    研讨内容：

    1. 分析基础模型合成能力与涌现机理在不同领域的应用价值

    2. 讨论基础模型合成能力与涌现机理的优势、局限和改进方向

    3. 讨论不同语言模型之间如何协作以产生更强大能力

    第四周：跨媒体智能与知识数据双轮驱动（杨易）

    课程内容：

    1. 介绍跨媒体智能的概念、特点和发展趋势

    2. 介绍知识驱动的人工智能的基本概念

    3. 介绍数据驱动的人工智能的基本概念

    4. 介绍跨媒体智能与知识数据双轮驱动的关系和互动机制

    5. 介绍基于跨媒体智能与知识数据的应用场景和案例

    研讨内容：

    1. 分析跨媒体智能与知识数据在不同领域的应用需求和挑战

    2. 讨论跨媒体智能与知识数据对人类认知、交流、创造等方面的影响和意义

    3. 讨论跨媒体智能与知识数据的质量、可信度和可解释性问题

    第五周：生成式人工智能前沿（汤永川 教授）

    课程内容：

    1. 介绍生成式人工智能与数字创意产业发展背景

    2. 介绍生成式人工智能的主要设计思想与关键技术

    3. 介绍生成式人工智能的应用领域和场景

    4. 介绍生成式人工智能的创新模式和案例

    研讨内容：

    1. 分析生成式人工智能在不同领域的应用效果和价值

    2. 讨论生成式人工智能对社会、经济、文化等方面的影响和意义

    3. 讨论生成式人工智能未来发展方向

    第六周：预训练大模型与未来教育变革（特邀：翟雪松）

    课程内容：

    1. 介绍教育的主要使命、特征和挑战

    2. 介绍未来教育变革的概念、目标和趋势

    3. 介绍未来教育变革的需求、挑战和机遇

    4. 介绍未来教育变革中人工智能大模型的作用和价值

    5. 介绍未来教育变革中基于人工智能大模型的教学设计和实践

    研讨内容：

    1. 分析预训练大模型对教育工具的影响

    2. 讨论预训练大模型对科技创新的促进、挑战和风险

    3. 讨论预训练大模型对教育公平的影响

    第七周：预训练大模型人工智能治理（潘恩荣 教授）

    课程内容：

    1. 介绍预训练大模型人工智能全球治理的关键时刻

    2. 介绍人工智能的可控性、安全行问题

    3. 介绍人工智能的偏见和公平性问题

    4. 介绍人工智能治理的模式、机制和标准

    5. 介绍通用人工智能的可行性和风险

    6. 介绍人工智能的自我意识和道德问题

    7. 介绍人工智能治理的国际合作和多边机制

    研讨内容：

    1. 分析人工智能治理的现状、问题和挑战

    2. 讨论人工智能治理的价值、利益和冲突

    3. 讨论人工智能治理的策略、路径和建议

    第八周：课程汇报

    课程内容：

    小组方式完成课程汇报。内容为：围绕课程内容进行的人工智能调研，重点是预训练大模型与所在专业的融合方式的调研和具体应用。
