# 工程测试与信息处理

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 工程测试与信息处理<br><small>ENER3202M</small> | 过控 · 25级及以前、26级<br>**专业选修 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程是一门专业技术基础课，本课程分为概论、信号分析基础、传感器测量原理、测试系统基本特性、计算机化测试系统和常见物理量测量与应用部分。通过本课程学习，学生能根据研究对象合理选择传感器、测试仪器及装置，掌握信号的采集、传输、变换及实验数据处理等动态测试所需要的基本知识和技能，并能了解掌握新时期测试技术的更新内容及发展动向。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本门课程的评分由两部分组成：

1）期末闭卷考试70％；

2）平时成绩30％【作业15％，传感器查阅报告5％，课堂问答问题、出勤占10％】
