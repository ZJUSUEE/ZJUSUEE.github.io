# 交通工程

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 交通工程<br><small>CCEA3702M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    《交通工程》这门课程从交通工程学的基础知识着手，系统阐述人、车、车流的交通特点，在此基础上引申到车流理论的探讨。同时，介绍交通调查与分析、交通规划、交通管理与交通控制、停车场的理论和应用；论述交通工程的主要评价指标；阐述交通安全和交通对环境的影响。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

期末闭卷考试开始占60％，课程作业占20％，实践作业（交通调查及改善设计）占20％。

### 课程大纲

??? abstract "展开查看"

    每周3学时，共16周。其中29学时用于课堂教学。

    主要内容：

    第一次 交通工程的绪论

    主要内容：交通工程的定义，交通工程学的发展历程与研究范围，交通工程的应用领域。

    1、交通工程学的定义、作用（掌握）

    2、交通工程学的形成和发展

    3、交通工程学的特点与其他学科的关系

    思政案例一：

    讲授交通在社会经济发展中“先行官”地位以及交通工程发展中的技术趋势。

    专业方面为学生系统讲授在交通在社会经济发展中“先行官”地位及提升交通运行效率的相关技术成果；在思政方面，通过作者的亲身经历，与学生分享作为一名普通共产党员在交通强国建设中的家国情怀：不畏艰辛、脚踏实地；攻坚克难、实事求是；勇于担当、甘于奉献；牢记一名交通从业者的初心和实干精神。

    以交通工程发展历史为例，以大家熟知的中国高铁、港珠澳大桥等标志性设施为切入点，先介绍交中国交通基础设施建设背景及工程概况；再在这个世纪工程建设成就基础上，回顾过去，看中国交通发展历史，一步步揭示我国交通工程技术与规模如何从弱变大、再从大到强；进一步展望未来，发挥制度优势，依靠科技创新、踏实肯干，让我国交通工程技术服务于“一带一路”，践行“交通强国”战略。

    第二次 交通特性分析

    主要内容：交通系统三要素，人的交通特性，驾驶员刺激-响应过程，制动与安全间距，道路特性。

    1、人、车、路交通特性（掌握）

    2、交通量特性（掌握）

    3、车速特性（掌握）

    4、三参数关系（熟练掌握）

    第三次 交通调查

    主要内容：交通流的概念与定义，交通流的状态变量，交通流基本关系式，连续交通流特性， 间断交通流特性。

    1、概述（掌握）

    2、交通量调查（掌握）

    3、车速调查（掌握）

    4、其他调查（掌握）

    第四次 交通流理论

    主要内容：了解时空图，交通检测中点（断面）检测法以及区间检测法，交通量、速度、密度、行程时间及延误调查法。

    1、概述

    2、交通流的统计分布特性（熟练掌握）

    3、波动理论简介（熟练掌握）

    4、流体动力学模型简介（掌握）

    第五次 通行能力

    主要内容：道路通行能力，服务水平的概念及计算方法，交通瓶颈，交叉路口，信号控制路口及无信号控制路口道路通行能力分析方法。

    1、概述(有关定义、作用) （掌握）

    2、路段通行能力计算（掌握）

    3、交叉口通行能力计算（熟练掌握）

    4、高速公路通行能力计算

    第六次 交通规划

    要点是了解和掌握交通出行的四阶段分析方法。

    主要内容：土地使用与交通出行，出行调查与预测，出行产生，出行分布，交通方式划分，交通流分配。

    1、概述(作用、发展、框图、程序)（掌握）

    2、调查工作（掌握）

    3、交通预测方法（熟练掌握）

    4、规划方案的制定与评价（熟练掌握）

    思政案例二，通过国内典型的新区综合交通规划案例，让学生了解交通工程系统的概念，明确交通行业社会责任感。

    通工程课程具有系统性、综合性和交叉性、社会性、超前性和动态性特点，与目前共同富裕示范区建设、双碳目标等热点目标紧密结合；同时交通系统是社会经济活动的支撑，在城市规划建设中交通处于先行地位。又由于道路基础设施建设和使用的周期较长，因此，交通系统规划和建设还要适应未来一定时期的交通需求。否则，一旦交通网络形成或预留用地不足，进行交通改善需要付出高昂代价，因此，交通系统必须要超前考虑、前瞻规划，交通工程课程必须依托现状，超前思考。

    以案例为基础，将理论、知识和技术穿插在案例中展开讲述，丰富和生动课程教学方法，调动学生学习积极性，增强学生家国情怀和职业责任感；选取中国特色新区杭州湾新区交通规划过程为案例进行教学，能涵盖课程中所以的内容体系和内容之间的关系，学生不仅能通过案例学习，而且能学完后进一步重复案例步骤，加深对课程的认识，在教学中不断提升学生探索问题兴趣和对学科知识的求知欲，进而提高教学质量和教学效果，同时对培养本科生自主学习能力具有重要实践意义。

    第七次 停车设施规划

    主要内容：停车调查，停车需求预测、停车场的规划

    1、概述

    2、停车场规划（掌握）

    3、停车场设计

    4、自行车停车

    第八次 交通管理和控制

    主要内容：城市道路交通管理的目的、分类；交通标志设计，标志的支撑物，交通标线，交通标线设计，交通标志标线的应用；城市道路交通控制，信号灯的特点及种类，信号控制参数，定周期控制，交通感应控制，信号系统配时，计算机信号控制系统

    1、概述(定义、作用)）

    2、交通管理（掌握）

    3、交通控制（掌握）

    4、交通信号控制参数（熟练掌握）

    思政案例三：

    通过讲授交通管理与控制的基本概念与方法，让学生掌握交通信号相关的技术与产业化情况。

    中国国产信号控制系统的研发基于国内的实际需求和自主创新的精神，而不是盲目地追随国外技术。学习中国国产信号控制系统的研发过程，可以让学生深刻理解到国家自主创新、始终坚持自力更生的原则的重要性，进一步增强爱国热情。同时，这也激发学生的工程实践热情和创新精神，培养学生面对挑战、追求卓越的品质。研发过程中多个部门、团队之间的紧密协作能让学生更关注团队合作精神。通过自研交通信号控制系统的案例学习，培养同学们无私奉献、吃苦耐劳、精益求精的工匠精神，成为心系社会并有时代担当的技术性人才。

    第九次 交通安全

    主要内容：交通事故的种类和类型，事故原因分析，安全评价指标

    1、交通事故定义

    2、交通事故调查

    3、交通事故分析（掌握）

    4、交通安全评价（熟练掌握）

    第十次 交通环境保护

    主要内容：大气污染物、交通污染形式及控制方式。

    1、概述

    2、交通废气污染及控制

    3、交通噪声及控制

    4、其它交通公害及控制
