# 汽车生产实习

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 汽车生产实习<br><small>ENER3408M</small> | 车辆 · 25级及以前<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    本课程为实习课程，主要介绍了汽车发动机曲轴、连杆、缸盖、缸体等的加工工艺和流程以及相关的工装夹具、汽车整车相关生产工艺和流程。同时本课程还参观实习发动机及整车出厂性能试验过程、新能源汽车前沿技术等。本课程适合有汽车设计、汽车构造相关背景的师生学习。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
