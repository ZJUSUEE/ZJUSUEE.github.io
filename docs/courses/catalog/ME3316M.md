# 机械工程基础实验

## 课程信息 {#course-information}

## 课程简介

??? abstract "展开查看"

    本实验课程是针对机械工程基础相关课程内容而设置，包含工程材料组织和属性分析；机械零部件常用几何参数测量；机械传动、运动和动力参数的测试和分析；机械摩擦和润滑的测试与分析，机构创新设计实验及虚拟仿真实验等。通过本实验课程的学习，使学生进一步理解和巩固机械工程基础理论知识，初步掌握机械实验原理、几何参数测量技术、测试技术、调试技术，数据采集、误差分析及处理、实验设计等内容的实验技术理论，提高实验设计与操作的能力，培养创新思维与工程素养。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

（1）实验报告：包括实验目的，实验原理，实验内容，实验结果（数据、作图等），思考题，实验心得等。

（2）考核方式：实验课考勤、操作等平时成绩：30%；实验报告：70%。
