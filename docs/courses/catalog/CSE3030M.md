# 数字图像处理与机器视觉

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 数字图像处理与机器视觉<br><small>CSE3030M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    本课程旨在引领学生系统学习机器视觉领域的相关概念、原理和方法，掌握视觉系统开发方法和实用技巧，为图像处理、模式识别等领域的研究与开发工作奠定基础。课程具体内容包括：机器视觉技术综述、视觉与成像原理、投影几何学、图像变换、图像分割、图像复原、视觉系统构建等内容。课程将采用讲授与讨论相结合的方法。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
