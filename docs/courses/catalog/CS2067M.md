# 人机工程学与创新设计

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 人机工程学与创新设计<br><small>CS2067M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    为工业设计专业系列课程的专业基础课，介绍人类工效学的形态学、生理学、心理学等方面的基础知识，并且着重介绍基于人类工效学的思考方法、价值观以及产品创新设计案例分析，以及人机工程学在产品设计中的应用与最新发展。培养学生通过人因研究与测试，获得解决实际的设计问题能力。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本课程的考核方式为考试和考察结合，平时作业分数作为平时成绩，最后考试、课程设计与平时成绩比例为40％－20％－40%。
