# 智能无人系统基础实践

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 智能无人系统基础实践<br><small>CSE1371M</small> | 储能卓工班 · 26级<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    本课程是卓越工程师本博贯通培养创新班本科阶段的入门级项目式课程，以智能无人系统为载体，围绕“感知—决策—执行”主线，引导学生完成从基础运动控制、环境感知与避障、路径规划与导航到综合任务的全流程实践。课程采用任务书驱动、微课+即时实践、阶段性里程碑考核等方式，帮助学生建立初步的“工程”概念，培养工程认知、动手实践、跨学科协同与问题解决能力，为后续《工程创新应用I》等进阶课程奠定基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

过程性考核60%：项目开题和方案设计（15%）、中期汇报（15%）、阶段报告（30%）。终结性考核40%：任务演示（20%）、项目答辩与结题报告（20%）。评价重功能达成、迭代过程和工程表达，不唯最优方案，允许试错。

### 课程大纲

??? abstract "展开查看"

    本课程共8次课，每次6学时，共48学时。采用“微课+即时实践”方式，每次课均包含知识讲授、动手实践和阶段任务。课程以麦轮机器人为载体，围绕“感知—决策—执行”主线展开，并为后续《工程创新应用I》等项目式学习奠定基础。

    第一次：智能无人系统概论与工程认知；ROS2环境搭建

    主要内容：（工程与科学问题的区别——智能无人系统的基本组成——“感知—决策—执行”闭环——ROS2环境搭建与节点通信初步）本课程从“什么是工程”切入，通过智能无人系统案例帮助学生建立工程概念。介绍麦轮底盘、深度相机、单线激光雷达、核心板等硬件组成，以及ROS2的基本架构。随后在实训场地完成ROS2环境搭建、节点通信与简单程序运行，为后续项目实践打下基础。本讲同时发布项目任务书，明确课程目标、考核方式与团队分工要求。

    阅读材料：

    《ROS2机器人编程实战》第1—2章。

    ROS2官方文档“Installation”与“Beginner: CLI tools”。

    自编《智能无人系统基础实践任务书与指导手册》第一讲。

    思考题/实践任务：

    结合一个具体无人系统（如机器狗、无人车），说明其“感知—决策—执行”分别对应哪些硬件和软件模块；完成ROS2环境搭建并运行一个简单节点通信示例。

    第二次：麦轮底盘运动控制与节点通信

    主要内容：（麦轮运动学基础——ROS2话题与服务——运动控制节点编写——实车调试）讲解麦克纳姆轮全向移动原理，以及如何通过ROS2发布速度指令控制底盘运动。学生动手编写或修改运动控制节点，实现前进、后退、转向、平移等基本动作，并在实训场地进行实车调试。通过“微课+即时实践”方式，让学生理解运动控制的基本流程和调试方法。

    阅读材料：

    《ROS2机器人编程实战》第3—4章。

    自编《智能无人系统基础实践任务书与指导手册》第二讲。

    麦轮底盘运动学参考资料（讲义）。

    思考题/实践任务：

    编写一个ROS2节点，让机器人按预定路径（如正方形、S形）运动；记录调试过程中遇到的问题及解决方法。

    第三次：传感器原理与数据采集

    主要内容：（深度相机与单线激光雷达工作原理——ROS2传感器消息类型——数据采集与可视化——标定基础）介绍深度相机和单线激光雷达的基本原理、数据格式和ROS2消息接口。学生动手完成传感器连接、数据采集与可视化（如RViz显示点云/激光扫描），并初步了解传感器标定方法。

    阅读材料：

    《ROS2机器人编程实战》相关章节。

    深度相机与激光雷达产品手册（节选）。

    自编《智能无人系统基础实践任务书与指导手册》第三讲。

    思考题/实践任务：

    在RViz中显示激光雷达和深度相机数据，分析不同传感器在环境感知中的优缺点；完成一次简单的传感器标定实验并记录结果。

    第四次：环境感知与自主避障

    主要内容：（避障算法基本思想——激光/视觉数据融合——反应式避障实现——现场调试）讲解基于传感器数据的反应式避障方法（如人工势场法、阈值避障等），引导学生设计简单避障策略。学生在实训场地布置障碍物，编写避障节点，实现机器人自主避障。通过迭代调试，理解感知—决策—执行闭环。

    阅读材料：

    《机器人学导论》相关章节。

    ROS2导航相关教程（避障部分）。

    自编《智能无人系统基础实践任务书与指导手册》第四讲。

    思考题/实践任务：

    设计一种避障策略，在仿真和实车中验证；分析避障失败的可能原因及改进方案。

    第五次：路径规划与自主导航入门

    主要内容：（SLAM建图基础——定位与地图——路径规划基本概念——ROS2导航栈使用）介绍SLAM建图与定位的基本原理，演示使用ROS2导航栈完成建图、保存地图、指定目标点导航。学生动手完成小范围建图与导航实验，理解路径规划、避障与定位的关系。

    阅读材料：

    《ROS2机器人编程实战》导航相关章节。

    ROS2 Navigation2官方文档。

    自编《智能无人系统基础实践任务书与指导手册》第五讲。

    思考题/实践任务：

    完成给定区域的SLAM建图，并让机器人从起点导航至指定坐标；记录建图误差、到点误差，分析影响因素。

    第六次：综合任务——巡逻搜索、识别、收集与返航决策

    主要内容：（综合任务发布——视觉识别基础——目标坐标估计——任务决策逻辑——团队分工）发布综合任务“自主巡逻与物品收集”。介绍基于深度相机的颜色识别与目标坐标估计方法，引导学生设计巡逻搜索、识别、收集与返航的决策逻辑。小组讨论并制定实施方案，分工开展代码开发与调试。本讲是“基础实践—进阶研发”递进链条的关键节点。

    阅读材料：

    《ROS2机器人编程实战》视觉相关章节。

    OpenCV/Python图像处理基础教程。

    自编《智能无人系统基础实践任务书与指导手册》第六讲。

    思考题/实践任务：

    设计综合任务的技术路线图；完成颜色识别模块的初步测试；制定小组分工与进度计划。

    第七次：综合任务联调与优化

    主要内容：（系统集成——模块联调——问题排查——迭代优化——中期检查）各组在实训场地进行综合任务联调，将运动控制、感知、避障、导航、识别等模块集成。教师和企业导师巡回指导，帮助学生排查问题、优化方案。本讲强调工程实践中的迭代思维和团队协作，要求记录调试日志和问题解决方案。本讲训练的系统联调与问题排查能力，是完成真实企业课题的基础。

    阅读材料：

    自编《智能无人系统基础实践任务书与指导手册》第七讲。

    项目调试日志模板。

    相关技术文档。

    思考题/实践任务：

    完成综合任务联调，记录至少3个问题及解决过程；提交中期进展报告。

    第八次：终期验收、项目答辩与总结反思

    主要内容：（任务演示——项目答辩——成果评价——总结反思——课程反馈）各组进行综合任务现场演示，展示机器人自主巡逻、识别、收集与返航的完整流程。随后进行项目答辩，汇报方案设计、技术路线、团队分工、遇到的问题与解决方案。教师和企业导师从功能达成、迭代过程、工程表达等维度进行评价。最后开展课程总结与反思，收集学生反馈，为课程迭代提供依据。

    阅读材料：

    自编《智能无人系统基础实践任务书与指导手册》第八讲。

    项目报告撰写规范。

    答辩评分标准。

    思考题/实践任务：

    提交项目结题报告与个人实践记录；完成小组互评与自评；提出对课程改进的建议。
