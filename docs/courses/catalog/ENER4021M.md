# 储能实验

## 课程简介

??? abstract "展开查看"

    储能实验课程紧密围绕国家双碳战略与新型能源体系建设需求，系统介绍物理储能、化学储能、热储能等各类先进储能技术的工作原理与相关理论，为开展实验奠定专业知识基础。并通过指导学生在实验室中参与搭建和运行不同类型的储能实验平台，开展系统充放能全过程的动态测量与综合性能评估，引导学生深入探究能量转换与存储的内在规律，并掌握典型储能技术的测试方法与操作规范，为进一步的专业学习奠定实践基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

考试方式：实验报告评阅。

评价方法：要求学生认真测试实验数据，提交实验分析报告，进行成绩考核。

成绩构成比例：

考勤制度20%，考勤；

实验环节20%，实验课动手操作能力；

讨论课评分10%，现场PPT展示及提问；

实验报告50%，实验结果处理与分析。

### 课程大纲

??? abstract "展开查看"

    第1-2次：储能实验课程介绍（2学分，线下）

    向学生介绍储能实验原理，介绍实验设备，操作流程。告知实验课安排，使学生对本课程的学习方法和学习要求有初步认识。主要内容包含：（1）储能技术分类及基本原理；（2）储能技术发展现状及应用场景；（3）储能实验平台及仪器设备介绍；（4）实验安全要求及数据处理方法。

    课外学习与作业要求：

    （1）了解我国能源结构背景和储能战略发展意义；

    （2）了解不同储能技术的优势、限制及典型应用场景。

    第3-4次：储能材料/元件的电学/热学/力学等特性测试（4学时，线下）

    通过实验使学生了解储能材料及储能元件性能测试方法，掌握电学、热学、力学等基本性能参数的测量原理及实验操作流程，培养学生实验数据采集与分析能力。主要内容包含：（1）储能材料及元件性能表征原理；（2）电学特性测试方法；（3）热学特性测试方法；（4）力学特性测试；（5）数据分析方法。

    课外学习与作业要求：

    （1）查阅储能材料电学、热学或力学表征方法文献；

    （2）理解测试参数物理意义；

    （3）完成基础性能表征实验数据分析报告。

    第5-6次：锂离子电池充放电性能测试（4学时，线下）

    通过锂离子电池恒流充放电实验，使学生掌握电化学储能系统性能测试方法，了解电池容量、充放电效率及循环性能等关键参数的测试与分析方法。主要内容包括：（1）锂离子电池工作原理；（2）电池恒流充放电测试方法；（3）充放电曲线及容量计算；（4）电池性能影响因素分析。

    课外学习与作业要求：

    （1）查阅锂离子电池工作原理及性能评价方法相关文献；

    （2）分析电池充放电曲线特征；

    （3）处理实验数据，完成实验报告。

    第7-8次：相变材料熔化与凝固过程的热性能测试（4学时，线下）

    通过相变储能实验，使学生了解相变材料储热机理，掌握材料熔化与凝固过程中的温度变化测试方法，分析储热性能及相变过程特征。主要内容包括：（1）相变储能基本原理；（2）相变材料熔化与凝固过程测试；（3）温度变化曲线测量与分析；（4）储热性能参数计算。

    课外学习与作业要求：

    （1）查阅相变储能材料相关文献；

    （2）分析相变过程中的热传递规律；

    （3）完成实验数据处理及实验报告。

    第9-10次：压缩空气储能实验平台热力过程测试（4学时，线下）

    通过压缩空气储能实验平台，使学生了解物理储能过程中气体压缩、储存及膨胀过程中的能量转换规律，掌握热力参数测试方法。主要内容包括：（1）压缩空气储能基本原理；（2）储能过程压力、温度参数测量；（3）系统热力过程分析；（4）储能效率计算。

    课外学习与作业要求：

    （1）查阅压缩空气储能技术相关资料；

    （2）分析压缩空气储能过程中的能量转换过程；

    （3）完成实验数据处理及实验报告。

    第11-12次：飞轮储能实验平台动态特性测试（4学时，线下）

    通过飞轮储能实验平台，使学生了解物理储能方式中旋转机械能存储与释放过程，掌握飞轮储能系统动态性能测试方法。主要内容包括：（1）飞轮储能基本原理；（2）飞轮转速变化过程测试；（3）动态响应特性分析；（4）储能与释能过程效率分析。

    课外学习与作业要求：

    （1）了解飞轮储能技术发展及应用；

    （2）分析飞轮转速变化与储能状态之间的关系；

    （3）完成实验报告。

    第13-14次：电解水制氢与燃料电池发电综合性能测试（4学时，线下）

    通过氢储能综合实验，使学生了解电解水制氢、氢能储存及燃料电池发电过程，掌握氢储能系统性能评价方法。主要内容包括：（1）电解水制氢原理；（2）燃料电池发电原理；（3）制氢效率及发电性能测试；（4）氢储能系统综合效率分析。

    课外学习与作业要求：

    （1）查阅氢储能及燃料电池相关文献；

    （2）分析电解制氢和燃料电池运行过程中的能量转换；

    （3）完成实验数据处理及实验报告。

    第15-16次：储能技术综合评价与应用场景分析（4学时，线下）

    通过课堂讨论和综合分析，使学生掌握不同储能技术评价方法，能够结合技术特点、经济性、安全性和应用需求，对储能方案进行综合评价。主要内容包括：（1）不同储能技术性能比较；（2）储能系统评价指标分析；（3）不同应用场景下储能技术选择；（4）储能技术发展趋势讨论。

    课外学习与作业要求：

    （1）查阅不同储能技术应用案例；

    （2）对电化学储能、热储能、物理储能和氢储能进行对比分析；

    （3）完成储能技术综合评价报告。
