# 新型电池设计与应用

## 课程简介

??? abstract "展开查看"

    本课程围绕新型电池的设计原理、关键材料、界面过程与应用场景展开，重点介绍锂离子电池、锂金属电池、锂硫电池、全固态电池、钠离子电池、锌离子电池以及钾、镁、钙、铝等其他新型电池体系。课程内容突出电池材料结构与性能、界面稳定性、失效机制、安全性、制造约束和应用需求之间的联系，并补充超级电容器及电池-电容混合储能器件内容。与电化学基础类课程相比，本课程更强调新型电池体系的材料设计、技术路线比较和应用场景分析，帮助学生建立从材料选择到器件设计、从实验性能到工程应用的综合认识。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

课堂讨论与出勤占20%，文献阅读或小组汇报占25%，阶段作业占25%，期末课程论文或开卷综合分析占30%。

### 课程大纲

??? abstract "展开查看"

    第一周：绪论：新型电池技术概述与性能指标

    新型电池技术的发展背景；新型电池在新能源汽车、规模储能、低温储能和便携设备中的应用需求；电池基本组成与性能指标，包括容量、倍率、能量密度、功率密度、效率、寿命和安全性；讨论不同应用场景对电池性能的取舍。

    第二周：电化学测试与电池图谱判读

    恒流充放电、循环伏安、线性扫描、电化学阻抗等常用测试方法；电流密度、扫描速率、截止电压和温度对测试结果的影响；结合典型曲线分析极化、容量衰减、内阻增长和界面过程。

    第三周：锂离子电池正极材料与应用

    锂离子电池工作原理；层状氧化物、尖晶石、橄榄石等正极结构；钴酸锂、锰酸锂、磷酸铁锂、三元材料和富锂锰基材料的性能特点；比较动力电池和储能电池对正极材料的不同要求。

    第四周：锂离子电池负极、电解质、隔膜与安全设计

    石墨、硬碳、钛酸锂、硅基负极等负极材料；SEI、首次库伦效率和体积膨胀；电解液、锂盐、添加剂和隔膜；过充、短路、快充析锂和热失控等安全问题。

    第五周：锂离子电池制造、性能衰减与锂金属电池概述

    电极浆料、涂布、辊压、装配、注液、化成和老化等制造过程；容量衰减、阻抗增长和副反应；金属锂负极的高容量优势、枝晶生长、死锂生成、低库伦效率和安全风险。

    第六周：锂金属电池界面膜与调控策略

    SEI组成、锂沉积/剥离过程和枝晶形成机制；高浓度电解液、局部高浓度电解液、人工SEI、三维集流体、亲锂层和外部压力调控；讨论接近实用条件的评价指标。

    第七周：锂硫电池设计与应用瓶颈

    硫正极多电子反应、多硫化物穿梭效应、硫绝缘性、体积变化和锂负极耦合问题；导电载体、极性吸附、催化转化、功能隔膜和贫电解液设计；分析高理论能量密度与实际能量密度之间的差距。

    第八周：全固态电池与固态电解质

    固态电池的发展背景和安全优势；氧化物、硫化物、卤化物和聚合物固态电解质；固-固接触、界面副反应、空间电荷层、锂枝晶穿透和堆叠压力；比较不同固态路线的工程化难点。

    第九周：聚合物/复合固态电解质与固态电池文献讨论

    PEO类聚合物、凝胶聚合物、单离子导体和复合固态电解质；复合正极、界面涂层、致密化和软包放大问题；组织学生阅读固态电池文献，分析测试条件与实用化判断。

    第十周：钠离子电池正极材料与应用场景

    钠资源和成本优势；Na+与Li+在半径、电位、溶剂化和扩散行为上的差异；层状氧化物、普鲁士蓝类化合物和聚阴离子正极；结合储能、两轮车和低温备用电源讨论材料选择。

    第十一周：钠离子电池负极、电解质与产业化边界

    硬碳储钠机制、斜坡区和平台区容量、首次库伦效率和预钠化；酯类/醚类电解液、钠盐和添加剂；比较钠离子电池与锂离子电池在能量密度、成本、安全和供应链方面的差异。

    第十二周：水系锌离子电池

    锌金属负极、水系电解液和正极嵌入/转化反应；析氢、腐蚀、钝化、枝晶、副产物和正极溶解问题；锰基、钒基、普鲁士蓝类正极和锌负极保护策略；讨论安全储能应用。

    第十三周：钾离子、镁离子、钙离子等新型电池体系

    钾离子电池的资源、电位和石墨嵌钾特点；镁、钙等多价离子电池的高体积容量潜力；强溶剂化、固相扩散慢、界面钝化和电解液兼容性等关键瓶颈。

    第十四周：铝离子电池与多体系横向比较

    铝金属负极、离子液体和水系铝电解质、石墨类正极和转化型正极；比较锂、钠、锌、钾和多价离子电池在能量密度、安全性、资源成本、成熟度和应用场景方面的差异。

    第十五周：超级电容器与电池-电容混合储能应用

    双电层电容、赝电容和混合型超级电容器；多孔碳、金属氧化物、导电聚合物和电解液；比较电池、超级电容器和混合储能系统在再生制动、调频储能、脉冲电源中的应用。

    第十六周：电池安全、回收、课程总结与学生汇报

    电池管理系统、热管理、滥用测试、梯次利用、材料回收和生命周期评价；学生围绕特定应用场景汇报新型电池技术路线；总结课程知识框架并答疑。
