# 人因工程与机器行为

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 人因工程与机器行为<br><small>CS3274M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    人因工程与机器行为是一门工业设计专业必修课。内容主要涉及产品设计中实现以人为中心设计理念的具体设计手段与方法，并且研究智能机器所表现出的行为。本课程结合实例，具体介绍通过人因研究与测试来获得基本设计数据的过程与方法，研究机器是如何发展一个特定的个体或集体行为的，并将其具体应用于解决实际的设计问题，培养新一代的科技设计人才。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本课程的考核方式为考查方式，平时作业分数作为平时成绩，其与最后大作业实验报告成绩比例为60％－40%。

### 课程大纲

??? abstract "展开查看"

    说明：本课程分课内和课外两个部分，课内又分教师讲授和学生讨论两个环节。课外每周约需两个学时的扩展阅读（阅读文献及书目见每周参考文献）和线上学习。

    第一周 人机工程与机器行为综述6学时

    理论讲授（4课时）

    主要内容：人机工程与机器行为的概念，人机工程与机器行为发展史，人机工程与机器行为研究概要。

    实践环节（2课时）

    主要内容：人机设计案例分析与讨论（能够有效降低书写负荷的人机工程学笔的设计）。

    第二周 人机工程与机器行为研究方法6学时

    理论讲授（4课时）

    主要内容：生理学研究方法，心理学研究方法，形态学研究方法，智能算法。

    实践环节（2课时）

    主要内容：从人机工程学角度出发列举好与不好的设计各三例。

    第三周 人体尺寸测量6学时

    理论讲授（4课时）

    主要内容：人体尺寸测量基本概念介绍，人体静态尺寸测量，人体动态尺寸测量，数据统计学处理方法。

    实践环节（2课时）

    主要内容：立姿测量（身高，上臂长，肩高，手功能高），坐姿测量（坐高，坐姿肩高，坐姿肘高，坐姿膝高，坐深，坐姿两肘宽），头部（头长），手（手长，第一与第五指尖最大距离）。

    第四周 环境人机工程与机器行为－光环境设计6学时

    理论讲授（4课时）

    主要内容：视觉系统，视觉发生机制，视觉特性与现象。

    实践环节（2课时）

    主要内容：光环境研究案例介绍与分析（汽车仪表盘照明设计对人体生理功能的影响），脑电图测量演示与学生具体操作练习，照明环境相关的脑电论文检索。

    第五周 环境人机工程与机器行为－声音环境设计6学时

    理论讲授（4课时）

    主要内容：听觉系统，听觉发生机制，听觉特性与现象。

    实践环节（2课时）

    主要内容： 声音环境研究案例介绍与分析（声音环境对行驶中驾驶员的生理及行为方面的影响），心电图测量演示与学生具体操作练习，声音环境相关的论文检索。

    第六周 人体作业系统6学时

    理论讲授（4课时）

    主要内容：人体肌肉骨骼系统构成，肌电产生机制，肌电图测量方法。

    实践环节（2课时）

    主要内容：肌电研究案例介绍与分析（为食品取出方便而设计的冰箱食品架的提议与评价），肌电图测量演示与学生具体操作练习，肌电相关的论文检索。

    第七周 人类与人工智能体之间的人机交互6学时

    理论讲授（4课时）

    主要内容：人类－机器混合系统运作机制的实验论证，人类和机器之间的相互作用。

    实践环节（2课时）

    主要内容：视觉交互研究案例介绍与分析（短视频内容、速度和比例对在线送餐菜单界面视觉注意力和主观感知的影响），眼动仪测量演示与学生具体操作练习。

    第八周 总结与复习6学时

    理论讲授（4课时）

    主要内容：人数据分析报告的一般方法及流程，指导学生设计实验。

    实践环节（2课时）

    主要内容：针对某一研究题目检测数据并撰写数据分析报告。
