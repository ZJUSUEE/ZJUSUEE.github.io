# 节能减排创新实践

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 节能减排创新实践<br><small>ENER2007M</small> | 热能、低温、新能源 · 25级及以前、26级<br>**实践课程 · 模块选修** |

## 课程简介

??? abstract "展开查看"

    本课程从推动大学生创新创业教育出发，以全国大学生节能减排社会实践和科技竞赛为具体的“双创”实践活动平台，鼓励广大在校生积极参加学科竞赛，通过学习如何完成一件高质量的创新科技作品，强化节能减排意识，提升创新实践能力，培养创新创业精神，锤炼强工报国本领。课程教学主要内容包括大学生从事科技实践活动必需的实验室安全知识教育，文献检索方法，科技写作和表达方法，科研专利申请等。通过作品案例分析，科学原理讲解，校外基地实习、专题分组讨论和项目设计答辩等形式对广大本科生进行创新实践教育，为今后的创新创业打下坚实基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本课程通过加强过程性考核和结课考试的方式进行综合能力的考查：

平时成绩：出勤率10%

实践活动调查问卷：10%

节能减排竞赛知识考试：50%

课程研讨报告（不少于2000字）：30%
