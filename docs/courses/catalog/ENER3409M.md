# 汽车核心课程综合设计

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 汽车核心课程综合设计<br><small>ENER3409M</small> | 车辆 · 25级及以前<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    本课程为汽车专业必修实践环节。通过本课程设计，加深学生对现代汽车电子控制一般原理的认识，掌握汽车电子控制中发动机转速、扭矩、水温、机油温度、进气温度、排气温度等物理量的测量原理和方法，学会硬件电路设计的基本步骤和软件设计的一般原则，为从事汽车电子相关工作打下理论和实践基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

按设计报告评分，其中：

硬件图纸：包括传感器电路、数字电路、输出接口电路；要求完成上述内容设计图纸，占比30%

软件流程图：要求完成方案设计，软件设计方法及流程图，占比30%

设计说明书：完成完整设计报告 占比40%
