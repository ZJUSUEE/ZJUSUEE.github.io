# 汽车技术综合实践

## 课程简介

??? abstract "展开查看"

    汽车技术综合实践是车辆工程专业学生的第一门基础实习课程。学生在实习之前已上过《汽车工程导论》课程，并且对汽车技术有了初步的了解，通过本课程的实习内容，使学生们对汽车的整体结构、动力系统、传动系统、底盘系统和座舱系统的工作原理有直观感性的认识，初步掌握汽车启动、起步、加减挡、加减速、制动等技能，会进行倒车入库、移库等基本操作，掌握基本的交通规则，为学习后续专业课程学习建立基础，并培养学生对汽车专业的兴趣和热爱。实习分为四部分：第一部分在汽车模拟驾驶仪进行驾驶，由带队老师进行讲解和辅导；第二部分在学校集中学习并参观汽车构造和性能相关的实验室，由实验室负责老师就实物和模型教具讲解汽车总体及各总成结构原理；第三部分到汽车驾驶培训中心，对学生分组，由教练员讲解交通规则，指导学生驾驶车辆，最后进行驾驶操作考核打分；第四部分以班级为单位由实习带队老师带领前往汽车生产或研发基地参观实习，由工厂技术人员讲解工厂安全规章制度，参观工厂，听技术人员讲解，提问答疑，并分组进行汽车总成的拆装实训，了解的整体结构、动力系统、传动系统、底盘系统和座舱系统的结构及其工作原理，培养学生的动手能力。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

（1）实习报告（60%）：包含实习记录、实习总结和实习思考题。

（2）实习现场表现（40%）（由指导教师、驾校方技术员和企业相关技术员共同评价）上述三项内容均记录在《实习记录本》上，实习结束后，将《实习记录本》统一送交带队教师，并作为学生实习成绩考核评分依据之一。

成绩评定：优秀、良好、中等、及格、不及格。

### 课程大纲

??? abstract "展开查看"

    （1）主要仪器设备

    1、紫金港校区汽车构造实验室汽车零部件一批；

    2、紫金港校区汽车构造实验室解剖透视车2辆；

    3、汽车企业生产设备；

    4、模拟驾驶仪6台；

    5、每4个学生配教练车1辆；

    6、每4个学生配教练员1名。

    （2）实验课程内容与学时分配

    （一）交通规则和驾驶规范学习 2天

    通过在多媒体教室集中授课的形式，介绍汽车的构成，工作原理、实习安排和注意事项，为学生介绍交通规则和驾驶规范的相关知识，并结合中国汽车产业的发展历程，将汽车电动化和智能化的发展方向融入思政教育内容。

    （二）模拟驾驶仪上模拟驾驶训练 1天

    在驾驶模拟器上进行驾驶训练。

    （三）汽车构造试验室实习 2天

    （1）专业实验室解剖车初步学习。

    在专业构造实验室通过指导教师对照汽车实物解剖模型进行初步讲解，组织观察认识。

    （2）专业实验室汽车零部件初步学习。

    在专业构造实验室通过指导教师对照汽车零部件进行初步讲解，组织观察认识具体结构，初步了解汽车零部件结构组成。

    （四）教练车实车驾驶 3天

    主要包括起步、换档、制动、停车、倒车等基本操作训练和直线穿桩等基础式样驾驶。基础驾驶训练是熟练掌握驾驶技术的关键。

    （五）车生产基地实习 2天

    （1）厂领导介绍工厂生产状况和厂区纪律。

    （2）燃油车和新能源汽车新车参观 。

    （3）工厂工程技术人员讲课，内容分别为：汽车结构及故障判断、汽车新四化技术在汽车上的运用和其他汽车新技术等。

    （4）实习分组；每5-6人为一组，各结构认识实习小组到所分配的实训小组进行各自实习内容，实习中期再交换进行。
