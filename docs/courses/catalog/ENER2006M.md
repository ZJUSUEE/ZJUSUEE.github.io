# 认识实习

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 认识实习<br><small>ENER2006M</small> | 热能、新能源 · 25级及以前、26级<br>**实践课程 · 实践必修** |

## 课程简介

??? abstract "展开查看"

    根据教学计划安排，在学完基础课及专业基础课之后，应到生产现场进行认识实习。学习电能生产的实际知识。对锅炉、汽轮机以及热工仪表、化水与电气系统等电能生产的各个环节增加一定的感性认识；学习各主要设备的结构及基本工作原理。为学习专业课打下基础。同时，学习电能生产的管理知识和组织技能，以培养学生分析问题和解决问题的能力。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

实习报告占70％，考勤与作业占30％。

### 课程大纲

??? abstract "展开查看"

    第1次课 火力电厂技术讲座：电厂系统

    理论讲授、讨论（4课时）

    主要内容：

    （1）全厂规模、装机容量、参数及系统布置。

    （2）电能生产的组织管理。

    （3）电能生产的技术分工、各业务范围。

    第2次课 火力电厂技术讲座：锅炉部分

    理论讲授、讨论（4课时）

    主要内容：

    （1）锅炉的型式、参数、整体结构特点。

    （2）煤-灰系统、风-烟系统、水-汽系统的流程路线、结构特点与作用。

    （3）受热面的布置，汽包、联箱、过热器、再热器、减温器、省煤器、空气预热器的结构形式及作用。

    第3次课 火力电厂技术讲座：汽机部分

    理论讲授、讨论（4课时）

    主要内容：

    （1）汽机型式、参数及热力系统。

    （2）汽缸、转子、叶片、隔板、喷嘴、轴封等的构造与作用。

    （3）凝汽器的结构与作用。

    （4）调速系统及保安装置的构造、作用原理；主汽门与调速汽门的作用原理。

    （5）抽气器、高、低压加热器、除氧器、凝结水泵、循环水泵、给水泵的型式、容量和构造。

    第4次课 火力电厂技术讲座：仪表、化学部分

    理论讲授、讨论（4课时）

    主要内容：

    （1）电力生产过程中要监视的主要热工参数。

    （2）测量温度、压力及流量的一次元件、二次仪表及工作原理。

    （3）本机组采用的自控系统及其工作原理。

    （4）化学水处理系统、原理、以及化学监督。

    第5次课 电厂仿真系统（VR）操作

    理论讲授、测试（4课时）

    主要内容：采用三维VR技术，构建与超低排放火力发电站一致的虚拟环境，学生通过试验台参观、电厂虚拟漫游、设备虚拟拆装和DCS参数调节等，全面掌握火力发电站各污染物脱除过程。

    （1）VR技术概述：介绍虚拟现实（VR）的基本概念、发展历程及主要应用领域。

    （2）VR设备介绍：讲解常见的VR设备及其使用方法，如头显、手柄等。

    （3）VR软件操作：培训如何操作基本的VR软件和平台。

    第6次课 电厂仿真系统（VR）操作

    理论讲授、测试（4课时）

    主要内容：

    （1）虚拟电厂结构：通过VR体验虚拟电厂的结构和布局，了解各个功能区域。

    （2）设备交互：在VR环境中与虚拟设备进行交互，熟悉设备的操作界面。

    （3）系统模拟：模拟电厂的日常运行和应急处理，观察系统反应和效果。

    第7次课 电厂仿真系统（VR）操作

    理论讲授、测试（4课时）

    主要内容：

    （1）故障模拟：在VR中模拟常见电厂故障场景，了解故障发生的过程和影响。

    （2）故障排查步骤：培训如何在VR环境中进行故障排查和诊断。

    （3）解决方案测试：测试和应用不同的故障解决方案，评估其效果。

    第8次课 电厂仿真系统（VR）操作与答疑

    理论讲授、讨论（4课时）

    主要内容：

    （1）安全风险识别：通过VR体验识别电厂操作中的潜在安全风险。

    （2）安全操作演练：在VR环境中进行安全操作和紧急响应的模拟演练。

    （3）应急处理流程：培训如何在虚拟环境中执行应急处理流程，提高实操能力。

    学生完成VR仿真操作后，老师对学生实习疑难点进行答疑。

    第9次课 华能长兴电厂参观

    理论讲授、讨论（10课时）

    主要内容：

    （1）电厂基本结构与功能：介绍华能长兴电厂的整体布局及各主要设施的作用。

    （2）安全操作规程：讲解电厂内的安全操作标准及紧急情况处理程序。

    （3）安全装备使用：培训如何正确穿戴和使用个人保护装备。

    第10次课 华能长兴电厂参观

    理论讲授、讨论（10课时）

    主要内容：

    （1）发电机工作原理：讲解发电机的基本工作原理和运行机制。

    （2）锅炉与汽轮机：介绍锅炉和汽轮机的功能及其在发电过程中的作用。

    （3）设备维护基础：培训如何进行设备的基本检查和维护。

    第11次课 华能长兴电厂参观

    理论讲授、讨论（10课时）

    主要内容：

    （1）运行控制系统：介绍电厂的运行控制系统及其操作界面。

    （2）负荷管理：讲解如何管理电厂的负荷，以优化发电效率。

    （3）数据记录与分析：培训如何记录和分析电厂运行中的关键数据。

    第12次课 华能长兴电厂参观

    理论讲授、讨论（10课时）

    主要内容：

    （1）环境保护法规：讲解电厂必须遵守的主要环境保护法规。

    （2）废气处理技术：介绍电厂常用的废气处理技术和设备。

    （3）污染物监测：培训如何进行污染物的监测和数据记录。

    第13次课 华能长兴电厂参观

    理论讲授、讨论（8课时）

    主要内容：

    （1）能源效率概念：讲解如何评估电厂的能源效率及其重要性。

    （2）节能技术应用：介绍节能技术在电厂中的应用实例。

    （3）节能改造案例：分析实际节能改造案例及其效果

    第14次课 华能长兴电厂参观

    理论讲授、讨论（8课时）

    主要内容：

    （1）电力市场结构：介绍电力市场的基本结构和运作模式。

    （2）经济效益分析：讲解如何进行电厂经济效益的分析与评估。

    （3）市场趋势与挑战：探讨当前电力市场的趋势和面临的主要挑战。

    第15次课 答疑

    理论讲授、讨论（4课时）

    主要内容：

    （1）课程内容总结：回顾前面课程的主要内容，帮助学生理清学习重点。

    （2）常见问题解答：解答学生在实习过程中遇到的常见问题和困惑。

    （3）知识点强化：针对学生的疑问进行详细讲解，确保学生对关键知识点有清晰的理解。

    第16次课 答疑

    理论讲授、讨论（4课时）

    主要内容：

    （1）实操问题解答：解答学生在实际操作或VR模拟中遇到的具体问题和挑战。

    （2）案例分析：讨论实际案例中的问题和解决方案，增强学生的实际操作能力。

    （3）学习反馈与建议：收集学生的反馈，提供针对性的建议，帮助他们进一步提升技能。
