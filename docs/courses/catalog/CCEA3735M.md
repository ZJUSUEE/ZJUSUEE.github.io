# 智能交通系统

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 智能交通系统<br><small>CCEA3735M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（智能车辆）** |

## 课程简介

??? abstract "展开查看"

    本课程以智能交通系统为对象，从智能出行服务、智能道路系统、智能车辆运行、智能交通管控等多个方面探讨智能交通系统的要素构成、功能特点和典型应用；以人-车-路系统的智能化为核心，分别介绍智能交通监视和信息处理、智能交通控制、智能出行信息服务与交通诱导、智能公交、智能高速公路、车联网、智能车辆与自动驾驶、车路协同、网联自动驾驶环境下的交通管控、智能交通与人工智能等内容。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容
