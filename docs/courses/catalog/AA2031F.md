# 理论力学（B）

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 理论力学（B）<br><small>AA2031F</small> | 过控、车辆 · 26级<br>**专业基础必修** |

## 课程简介

??? abstract "展开查看"

    理论力学是工科大类专业基础课，内容包括静力学、运动学与动力学三部分。静力学部分从静力学公理出发，研究力系的简化与力系的平衡；运动学部分研究点和刚体的运动描述、点的合成运动及刚体平面运动；动力学部分研究动力学普遍定理、动静法、虚位移原理、动力学普遍方程、拉格朗日方程及振动基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

<h2 id="reference-_9">学习建议</h2>
<div class="tabbed-set tabbed-alternate" data-tabs="1:1"><input checked id="reference-__tabbed_1_1" name="reference-__tabbed_1" type="radio"><div class="tabbed-labels"><label for="reference-__tabbed_1_1">shadow1723(25-26秋冬)</label></div>
<div class="tabbed-content">
<div class="tabbed-block">
<p>​回忆卷可见我另一个帖子<a href="https://www.cc98.org/topic/6401272">25-26 理论力学（甲）回忆附经验分享</a> ,王永老师是一个很好的老师，而且很适合自学。如果后续学习的同学觉得自己能够自学，或者和lz一样，需要冲突选课的话，可以选择王永老师的理力甲，他的讲义和例题与习题特别适合自学和期末复习，而且例题与习题里面的题很多都是来自历年卷或者考研题，都是搜不到答案的，自己一学期坐下来，面向历年卷复习的时候也会感觉很轻松。</p>
<p>btw，这学期的理力甲的试卷难度确实远超历年卷了，lz做历年卷还能稳定做出3-4道题，这套卷子我只能说感谢永神海底捞了。然后说一下混分经验吧，理力期末分为五个板块：静力学，运动学，动力学，达朗贝尔原理，虚位移：</p>
<p><strong>静力学</strong>：他定位就是送分的题目，分值是20分。wy在复习课说今年这题学得好半分钟就能做出来，确实比较简单。然后这题20分想要拿18-9也是有万能办法的（wy亲授）：就是实在不会这道题，把每个构件每个节点等受力分析，列三个平衡方程，∑ F<sub>x</sub> = 0、∑ F<sub>y</sub> = 0、∑ M = 0，方程一定可解，就算没解出来，也能拿18-9分[ac01]。但是不推荐这个办法，wy也说了，不希望看到他班上的学生这么做，lz的经验是：先整体看一下，画出整体的受力，整理列一下平衡的三个方程。如果可解，那万事大吉，不可解就找其他受力简单的构件进行分析，比如二立杆等。然后记住一些常见模型怎么快速分析，比如这次期末，直接在两个墙上的固定铰链处取矩就能解出来，这些模型wy的例题习题都有，所以还是最好考试前过一下例题与习题。</p>
<p><strong>运动学</strong>：wy在考前就说，这次运动学这道题很难。确实很难，我到现在也不会做，但是混分是有技巧的：首先就是瞬心法，如果物体瞬心好找，一定要找到物体的瞬心，然后基点法，用一个已知速度或者加速度的点作为基点，表示构件上未知速度或者加速度的点，这两个应该是解题步骤和得分要点中第一个占比大分的点，写全了，其实基本都能解一些，应该就拿到差不多1/3的分数了。然后最重要的就是运动的合成与分解部分，这道题肯定会涉及到的，所以要弄清楚一般动点动系的选择，牵连速度的定义到底是什么，还有一些常见的设动点动系的方法，这些最好心理有个谱。然后lz期末做这道题肯定是错的，不会这么简单，所以lz采取了混分策略，写了个运动分析，把基点法一列，速度的合=合成与分解的速度，加速度式子一列，然后解出来，虽然答案肯定是错的，好像少了什么方程。但是这几个混分，还有中间的表示的几个式子一定的对的，所以lz这20分得分应该不会很低。</p>
<p><strong>动力学</strong>：这道题分值25分。重要性不用多说了，内容也比较多。所以期末在看wy讲义的时候重点就在看这个。为了期末覆盖面全，wy说题一般结合能量法一起考，所以第一步比较固定，列能量方程，找到各构件速度关系，列出方程解出来就ok，然后第二部分涉及到加速度和力的计算，就稍微比较复杂了。lz想说的是，达朗贝尔原理也是牛顿力学里面的一部分。虽然第四题限制使用达朗贝尔原理解题，但是本题不限制使用什么方法，所以想要混分的同学可以把用物系独立坐标数目的加速度，将各构件的惯性力表示出来，画上去，然后框框列几个方程就好，这次期末考试，lz设了两个角加速度，两个构件各一个，然后约束力约束力偶一画，整体三个平衡方程，杆补充一个，两个加速度关系补充一个，加上要解的力，一共5个未知数5个方程，方程一定可解，但是lz并没有解，一是写不下了，二是要花很多时间，lz感觉性价比很低，所以到这就结束了，但是过程一定是对的，我估计25分，lz这样做应该是拿了21+</p>
<p><strong>达朗贝尔原理</strong>：因为动力学是那种有位置能用能量方法做的题目，所以为了期末覆盖面全，这题一定是瞬时问题，就是求他瞬时的加速度。题目流程比较固定，就是设设加速度，一般是角加速度，然后可能用一下加速度基点法，表示出各物件质心加速度，表示各物体惯性力，惯性力偶。然后又是框框列方程，这道题还是比较简单的。所以建议还是解出来，不解，只要方程列对应该也能拿17-8分左右吧。而且这次期末这道题，wy的习题部分有和他类似的题，但是并不一样，习题是圆环和杆固定的，这道题是铰接，但是换汤不换药，其实大体做法是一样的，但是这道题本身定位也是半送分，只要差不多会达朗贝尔原理，都差不多会做这道题</p>
<p><strong>虚位移原理</strong>：很简单的，这个甚至比静力学还要送分。备考建议学会解析法和几何法，解析法就是选取独立坐标标出各点然后求导，几何法就是根据构件运动，逐步表示每个点的变分，受期末复习影响，lz这部分没咋学，讲义也没看，但是看了例题与习题，这次期末解析法就很好做，表示出来直接求导就好，但是23-24年期末几何法又更简单。所有各有优劣吧，但是都比较简单，所以建议都最好会做。</p>
<p>总的来说，理力甲确实比较难，运动学和动力学都算很难的，且战45分，所以做题建议顺序为15423或者15432，lz是在知道这次运动学很难，所以选择了15432的顺序，然后2题基本就完全是混分，3题最后的方程也没解出来。但是所幸结果还算很好，wy老师比较捞。平时分的话，建议在群里面多讨论，不管自己会不会，让老师记住你，或者期末考个比较好的分数，老师也不会在平时分上为难你，然后按时交作业，不管正确率如何，两次实验按时做，按时交报告。这样平时分应该问题也不大。</p>
