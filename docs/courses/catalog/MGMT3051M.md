## 课程简介

??? abstract "展开查看"

    在复杂而充满不确定性的商业环境中，优化与仿真方法通常作为管理与决策的辅助工具。传统优化方法基于问题的几何、代数性质，主要特征为精确、严格与确定。在实际操作中，建模技巧要求较高，求解问题规模较小，难以处理一些不确定、不精确、动态的或者对计算时间要求较严格的问题。智能优化方法通过对自然界的模仿来应对上述问题，从而更好地处理复杂、不确定、不精确或动态的问题。仿真优化方法则利用仿真技术进一步处理系统中的随机性和动态性，从而帮助人们解决优化过程中的高维度、动态性等困难。两者在处理不确定性中的共性和互补性使得在处理复杂决策时很容易将两者进行融合进而构建高效复杂的决策支持系统。本课程将围绕智能优化与仿真的原理、算法以及对决策的支持等问题展开，使学生对如何利用智能优化与仿真方法解决问题有一定的了解。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
