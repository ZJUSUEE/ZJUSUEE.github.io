# 材料科学基础Ⅰ

## 课程简介

??? abstract "展开查看"

    “材料科学基础”课程涉及金属材料、无机非金属材料及半导体功能材料等本身的基础与科学问题，以介绍材料学的基本理论为原则。“材料科学基础” 课程(第一部分)，以材料的结构状态为主线，详细介绍包括：晶体结构、晶体的不完整性、固溶体、非晶态材料结构、固体扩散等在内的全部内容，覆盖了固体材料基本结构的基础知识与基本理论问题，牢固树立德才兼备，精材成器，为国家做贡献的价值观。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

课程考核主要分为理论授课部分考试和平时成绩。平时成绩为平时作业和课堂互动等成绩。其中期终考试成绩与平时成绩中，考试占50~60%，平时成绩占50~40%。

### 课程大纲

??? abstract "展开查看"

    第一周 前言晶体结构-晶体学基础

    2课时：材料基本概念，晶体学发展历史、晶体基本性质。

    2课时：空间点阵，晶向指数、晶面指数、六方晶系指数。

    第二周 晶体结构

    2课时：晶体的对称性: 宏观对称性，宏观对称要素。

    2课时：晶带概念的介绍及应用，晶面间距的计算，晶面指数的变换，极射赤面投影。

    第三周 晶体结构

    2课时：晶体的对称性具体为宏观对称要素及其组合。

    2课时：宏观对称要素及其组合及点群。

    第四周 晶体结构

    2课时：晶体的微观对称操作，对称操作元素及其组合

    2课时：晶体的围观对称操作组合定理

    第五周 晶体结构

    2课时：空间群，范霍夫位置

    2课时：原子电负性相关概念，键型、键的结合能和结合力、原子半径，具体为金属结合（金属键）、离子结合（离子键）、共价结合（共价键）的结合能和结合力的介绍。

    第六周 晶体结构

    2课时：原子半径相关的基本概念以及金属晶体、晶体中原子间的间隙等知识。

    2课时：离子晶体中的多面体规律及典型的离子晶体结构。典型晶体结构等内容。

    第七周 晶体结构

    2课时：介绍硅酸盐晶体的分类和硅酸盐矿物结构以及岛状结构、环状结构、链状结构、层状结构等的基本概念。高分子晶体的典型晶体结构， MOFs及新型有机无机杂化钙钛矿结构等

    2课时：典型晶体结构基础知识讨论课。

    第八周 晶体缺陷

    2课时：晶体的不完整性介绍点缺陷的类型和点缺陷的反应与浓度平衡，具体为热缺陷、组成缺陷、电荷缺陷、非化学计量结构缺陷、色心以及各种缺陷的反应与浓度平衡。点缺陷的类型包括：热缺陷，组成缺陷，电荷缺陷。点缺陷的运动包括：原子的热扩散和电迁移。

    2课时：介绍位错类型、Burgers回路与位错的结构特征、位错密度以及位错的应力场等相关基础知识。其中位错的类型包括刃位错，螺位错，混合位错，位错核结构。位错的应力场包括应力分量，应变能与线张力等。

    第九周 晶体缺陷

    2课时：晶体中位错的运动，介绍位错的滑移、位错攀移，位错与缺陷的相互作用。

    2课时：位错之间的相互作用、位错与点缺陷的相互作用及位错源与位错增殖。

    第十周 晶体缺陷

    2课时：晶体表面，具体为晶体的表面力场、晶体表面状态、晶体表面的不均匀性

    2课时：晶界几何，小角度晶界、大角度晶界，晶界能、孪晶界、晶界的特性等

    第十一周 固溶体

    2课时：固溶体的概念，休姆-罗瑟里(Hume-Rothery)规律、尺寸因素、电价因素、电负性因素等相关知识。置换固溶体，间隙固溶体，有序固溶体-短程有序，长程有序。

    2课时：固溶体的理论分析与计算-理论密度计算相关知识以及电子化合物、间隙相、间隙化合物、拓扑密堆相等中间相相关知识的介绍。

    第十二周 晶体缺陷与非晶材料

    2课时：晶体缺陷与固溶体基础知识讨论课

    2课时：非晶材料概论

    第十三周 晶体缺陷

    2课时：非晶态固体的结构特征。非晶态固体的结构表征函数：径向分布函数RDF、结构描述参数。

    2课时：非晶态固体的短程序：化学短程序（CSRO）、几何短程序(GSRO)与局域结构参数。

    第十四周 晶体结构

    2课时：非晶半导体的结构模型。非晶半导体的微结构。典型非晶态半导体结构特征；以及非晶态金属，典型非晶金属结构特征。

    2课时：玻璃结构理论：玻璃结构的无规网络学说、玻璃结构的微晶子学说、常见玻璃的微观结构；玻璃的转变。

    第十五周 晶体结构

    2课时：菲克定律，稳态扩散及其应用；主要介绍菲克第一定律及菲克第二定律，一维稳态扩散，柱对称稳态扩散，球对称稳态扩散，一维无穷长物体的扩散。

    2课时：半无穷长物体的扩散和有限长物体的扩散，非稳态扩散及其应用。

    第十六周 晶体结构

    2课时：固体中的扩散：Kirkendall效应，Darken公式，扩散的微观理论、机制及其影响因素；

    2课时：非晶固体和固体扩散讨论或阶段性测试。
