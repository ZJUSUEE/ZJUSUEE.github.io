# 过程装备智能制造技术

## 课程简介

??? abstract "展开查看"

    在制造业整体向智能化、高效化和绿色化发展的背景下，过程装备制造也趋向与智能制造等先进制造新技术深度融合，向高度机械化、自动化和智能化方向发展。本课程将智能制造技术引入过程装备制造，联系产业生产实际，围绕过程装备制造基础、智能制造基础、智能制造关键技术、智能制造实施案例、智能工厂等展开。通过学习，使学生了解智能制造基本理论、架构和应用，了解智能制造在过程装备制造工艺中的应用及其重要影响，要求学生能够适应和掌握当今数字化、智能化时代背景下的过程装备智能制造的基本理论和知识。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    说明：本课程以理论授课为主，线上实践操作为辅。授课约需16周，至少4课时需要学生进行虚拟实践操作。

    第一周 过程装备制造基础1

    1. 过程装备制造概述；

    2. 典型过程设备制造流程及工艺。

    理论讲授（2课时）

    主要内容：过程装备的概念；典型过程装备的制造流程；过程装备常用制造工艺；压力容器制造流程；划线与切割；卷板与滚弯；焊接。

    第二周 过程装备制造基础2

    1. 典型过程机器制造流程及工艺；

    2. 过程装备的质量检验。

    理论讲授（2课时）

    主要内容：泵的制造流程；毛坯制造；机械加工；装配与调试；过程设备质量检验的目的、内容和方法；无损检测；过车设备的试压及密封性检查。

    第三周 智能制造概述

    1. 智能制造的定义和特征；

    2. 智能制造的系统架构；

    3. 智能制造的系统组成和发展趋势。

    理论讲授（2课时）

    主要内容：智能制造的定义和特征；智能制造系统定义和总体架构；智能制造标准体系结构；智能制造标准体系框架；传感器与数据采集；数据存储与处理；通信与网络协同；自动化与控制系统；软件与算法；人机交互界面。

    第四周 智能制造关键装备1

    1. 智能数控机床；

    2. 工业机器人；

    3. 增材制造装备。

    理论讲授（2课时）

    主要内容：智能数控机床；工业机器人的定义和特点；工业机器人的分类和组成；工业机器人在智能制造中的典型应用；增材制造的定义和特点、增材制造的分类。

    第五周 智能制造关键装备2

    1. 智能传感器；

    2. 智能物流装备。

    理论讲授（2课时）

    主要内容：传感器与智能传感器；智能制造中常见的传感器；智能传感器的应用场景；智能物流装备分类；自动引导运输车（AGV）；自动化立体仓库。

    第六周 智能制造关键技术1

    1. 工业物联网；

    2. 工业通讯技术；

    3. 工业大数据。

    理论讲授（2课时）

    主要内容：工业物联网的定义；工业物联网在智能制造中的应用；工业现场总线通信技术；工业以太网通信技术；工业无线通信技术；5G通信技术；大数据与工业大数据；工业大数据与智能制造。

    第七周 智能制造关键技术2

    1. 云计算与边缘计算；

    2. 虚拟现实/增强现实；

    3. 数字孪生；

    4. 人工智能。

    理论讲授（2课时）

    主要内容：云计算；边缘计算；虚拟现实技术；增强现实技术；混合现实技术；VR/AR/MR在智能制造中的应用；数字孪生的概念；数字孪生在智能制造中的应用；人工智能的概念；人工智能+制造。

    第八周 实验实践

    实践教学1（1课时）

    实践内容：工业机器人虚拟仿真软件实践操作。

    实践教学2（1课时）

    实践内容：认识虚拟现实开发工具；智能制造虚拟现实案例实践；。

    第九周 智能制造工业软件

    1. 工业软件的定义和分类；

    2. 企业资源计划（ERP）；

    3. 制造执行系统（MES）；

    4. 产品全生命周期管理（PLM）。

    理论讲授（2课时）

    主要内容：工业软件的定义和分类；ERP的定义；ERP在智能制造中的作用；典型的ERP系统；MES的定义；MES的核心功能模块；MES在智能制造中的应用；PLM的定义；PLM在智能制造中的应用；PLM与ERP、MES等的关系。

    第十周 智能制造生产线设计与仿真1

    1. 智能制造生产线；

    理论讲授（2课时）

    主要内容：智能制造生产线的特征与基本要求；智能制造生产线的组成单元。

    第十一周 智能制造生产线设计与仿真2

    1. 智能制造生产线设计与布局。

    理论讲授（2课时）

    主要内容：智能制造生产线的设计方法；布局原则；设计流程；工艺设计。

    第十二周 智能制造生产线设计与仿真3

    1. 流程型智能制造生产线；

    2. 离散型智能制造生产线；

    3. 智能生产线数字孪生和仿真。

    理论讲授（2课时）

    主要内容：流程型智能制造生产线的特点；流程型智能制造生产线总体设计、工艺流程和布局；离散型智能制造生产线的特点；离散型智能制造生产线总体设计、工艺流程和布局；工业数字孪生；数字化产线建模与仿真的重要性。

    第十三周 实验实践

    实践教学（2课时）

    实践内容：虚拟智能制造生产线搭建和运行。

    第十四周 过程装备智能加工案例

    1. 压力容器智能加工案例；

    2. 泵智能加工案例；

    3. 微小流道增材制造案例。

    理论讲授（2课时）

    主要内容：压力容器智能加工案例（盈德工程）；泵智能加工案例；微小流道增材制造案例。

    第十五周 智能工厂

    1. 智能工厂的基本架构；

    2. 智能工厂的基本特征；

    3. 智能工厂案例。

    理论讲授（2课时）

    主要内容：智能工厂的基本架构；基本特征；德玛仕、集智、友成等智能工厂案例。

    第十六周 实验实践

    实践教学（1课时）

    实践内容：智能工厂交互式360全景线上“云实践”。
