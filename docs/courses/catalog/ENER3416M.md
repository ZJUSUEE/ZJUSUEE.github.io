# 车用动力电池技术

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 车用动力电池技术<br><small>ENER3416M</small> | 车辆 · 26级<br>**专业选修** |

## 课程简介

??? abstract "展开查看"

    车用动力电池技术主要介绍新能源汽车动力电池的基本原理、关键材料、系统结构、成组技术、管理方法及应用现状，是能源与动力工程、新能源科学与工程、储能科学与工程等专业的一门重要技术基础课。课程内容涉及电化学、材料学、传热学、电气工程及车辆工程等相关基础知识，主要包括动力电池概述、锂离子动力电池基础、动力电池关键材料、电池制造工艺、电池性能与测试、动力电池成组技术、电池管理系统、热管理技术、动力电池安全与梯次利用等内容。通过本课程学习，学生能够掌握车用动力电池的基本原理和关键技术，了解动力电池的发展趋势及其在新能源汽车领域中的应用。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
