# 机械振动基础

## 课程简介

??? abstract "展开查看"

    本课程是为大学本科高年级学生开设的一门专业基础课。着重介绍机械系统的线性振动理论及其在工程实际中的应用，包括单自由度、两自由度、多自由度系统的自由振动、阻尼振动和强迫振动的基本理论和工程应用，以及连续系统振动的基本理论。使学生建立机械振动的一系列基本概念，能够运用所学的力学原理和数学知识建立相应的数学方程从而将振动问题归结为数学问题的典型力学方法。并能使用Matlab软件进行振动问题的求解和分析。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

### 课程大纲

??? abstract "展开查看"

    1）第0章 绪论（2学时）

    课程的内容和任务，机械振动的工程应用背景、振动的分类、振动系统的力学分析模型。介绍机械振动在中国古代的应用，以及机械振动理论的发展过程，介绍在我国神舟飞船、空间站、登月车、火星飞行器、大飞机、航空发动机和燃气轮机、高铁建设、大型桥梁和摩天大楼建设、石油储备库等大型工程中的机械振动问题，介绍生活中遇到的地震、噪音、手机等振动问题。从而激发学生学习机械振动的技术和生活应用兴趣。

    2）第一章 单自由度系统的振动（6学时）

    振动系统的力学模型及自由度的概念；弹性元件的形式和刚度；振动微分方程的推导；无阻尼自由振动；固有频率的计算；粘性阻尼对自由振动的影响；无阻尼受迫振动；具有粘性阻尼的受迫振动；等效粘性阻尼的概念；单自由度系统振动的利用及振动分析；单自由度系统的减动；机械结构的动应力和动刚度的概念。

    3）第二章 二自由度系统的振动（8学时）

    应用动静法建立方程式；应用拉格朗日方程建立方程式；振动方程的一般形式及其矩阵表示法；无阻尼二自由度系统的自由振动；无阻尼二自由度系统的受迫振动；具有粘性阻尼的二自由度系统的自由振动；具有粘性阻尼的二自由度系统的受迫振动；二自由度振动系统的利用及振动机械的振动分析；振动机械及测试机器的二次隔振；动力减振原理与动力减振器。

    4）第三章 多自由度系统的自由振动（6学时）

    多自由度系统举例；刚度矩阵与刚度影响系数；柔度矩阵与柔度影响系数；惯性藕联和弹性藕联；固有频率与振型矩阵；多自由度系统的受迫振动；无阻尼系统受迫振动的响应；多自由度系统的阻尼；有阻尼多自由度系统对激振的响应。

    5）第四章 线性振动的近似计算方法（2学时）

    本章介绍邓克莱法，瑞利法，里茨法，传递矩阵法等几种近似计算方法，可作为实用的工程计算方法对机械振动系统的振动特性作快速、近似计算。

    6) 第五章 连续系统的振动（8学时）

    实际的振动系统都是连续体，它们具有连续分布的质量与弹性，因而又称连续系统或分布参数系统。由于确定连续体上无数质点的位置需要无限多个坐标，因此连续体是具有无限多自由度的系统。连续体的振动要用时间和空间坐标的函数来描述，其运动方程不再像有限多自由度系统那样是二阶常微分方程组，它是偏微分方程。

    本章首先介绍杆的纵向振动、弦的横向振动、轴的扭转振动等一维波动方程动力学方程的建立，再根据边界条件求解固有频率和模态，然后通过变量分量代入动力学方程，利用正交性条件得到模态空间中解耦后的动力学方程，并将物理空间中的位移和速度初始条件转化到模态空间，在模态空间实现解耦方程的求解，然后返回物理空间得到系统的运动求解。

    然后再讲解伯努利-欧拉(Bernoulli-Euler) 细长梁的横向弯曲振动微段受力分析和动力方程建立，分析固定端、简支端、自由端三种常见约束状况与边界条件下梁横向弯曲振动的固有频率和模态函数，介绍典型铅垂染的前三阶模态形状。进一步介绍如何采用模态函数的正交性条件，求解梁横向振动的强迫振动响应。
