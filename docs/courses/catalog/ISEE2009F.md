# 电子工程训练（乙）

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |

## 课程简介

??? abstract "展开查看"

    本实验课程通过对电子元器件的认知、电路组装工艺的认知和实际电路安装操作、电子测量仪器的使用训练，了解电子信息系统的硬件基础构成，初步掌握电子电路基本实验技能；再通过对智能系统的安装、调试与应用操作，移动视觉智能系统的系统集成组装调试等电装制造工程操作、电子信息系统的软硬件安装调试等方面的动手实践，帮助学生建立起电子设备制造工艺与电子系统理念、电子系统安装调试规范以及提高电子工程技能，了解电子信息系统软硬件的基本构成，为后续学习和研究建立基础。注重科学思维方法的训练和科技伦理的教育，培养学生探索未知、追求真理、勇攀科学高峰的责任感和使命感，培养学生精益求精的精神。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

课程采用基于项目的考核方式，考核内容包含：

1.1. 项目一 作品验收

1.2. 项目一 总结报告

1.3. 项目二 成品验收

1.4. 项目二 测试总结报告

1.5. 项目三 成品组装验收

1.6. 项目三 成品功能验收

1.7. 实践总结报告

1.8. 到课率和规范检查

成绩评定方法：

总成绩=期末成绩\*0.5+平时成绩\*0.5

平时成绩:考核1+考核2+考核3+考核4

期末成绩:考核5+考核6+考核7+考核8
