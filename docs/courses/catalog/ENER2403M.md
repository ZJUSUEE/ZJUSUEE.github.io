# 智能车辆创新实践

## 课程信息 {#course-information}

## 课程简介

??? abstract "展开查看"

    为帮助车辆方向大二本科生了解智能车辆的基本原理，这门短学期课程以面向模型车实车竞技项目的方式，在AI大模型辅助下开展集中实践授课。课程包括基础共性教学和专业个性实践两个部分。基础共性教学包括车辆平台熟悉、AI辅助编程方法讲授、算法原理讲解与代码实践；个性实践主要指学生在指导老师现场指导下，以三人小组为单位，借助AI大模型辅助编程，完成智能车辆感知、决策、规划、控制四个模块的代码学习、改进与系统联调，最终通过实车竞技比赛检验成果。通过本课程的学习，可以以点带面地激发学生学习智能车辆专业知识的主动性和积极性，强化学生的AI辅助编程能力与工程实践创新能力培养，实现理论知识、代码实践与实车验证的有效融通。

    来源：[教务网](https://zdbk.zju.edu.cn/)。
