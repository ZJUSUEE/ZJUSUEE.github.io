## 课程简介

??? abstract "展开查看"

    《过程微纳米技术与装备》是面向过程装备与控制工程专业和能源、材料、机械类本科生开设的专业课，共32学时。内容涵盖微纳米工艺技术和过程微装备的基础知识，通过本课程的学习，使学生掌握纳米科技与纳米材料、微纳米流动控制及其检测技术的基本概念，分析过程微纳米装备的基本原理、结构设计及应用，拓宽过程装备与控制工程及相关专业学生的知识面，为从事微纳米技术和微装备行业的工作奠定基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

本课程的评分分为三个部分，每个部分分数分配如下：出勤10%；课堂练习30%；期末课程论文60%。

### 课程大纲

??? abstract "展开查看"

    本课程介绍工业过程微纳米技术及其装备的基础知识及其最新技术发展情况，主要内容包括如下两大部分：

    第一部分：过程微纳米技术基础，学时数为12。

    1）绪论、基本知识；2学时

    微纳米技术是当今科学技术领域的一个国际前沿研究的重点方向，在过程装备、材料成型、能源工程、光电信息、生物医学、国防科技等多个领域都有着广泛的应用，微纳米过程装备是实现微纳米过程工艺技术应用的关键。主要介绍微纳米技术及其在过程工业应用的工艺原理和新型微纳米过程装备。

    2）纳米科技与纳米材料；2学时

    纳米科技是纳米科学与纳米技术的统称，融合了物理学、材料科学和生物学等学科，涉及在原子和分子尺度上对材料的操纵的学问；纳米技术是在纳米尺度上观察、测量、操纵、组装、控制和制造物质的技术。纳米材料根据维度可分为一维纳米材料、二维纳米材料、三维纳米材料，因其特殊的尺寸效应、表面效应和量子效应而表现出与其宏观尺度不同的物理、化学和生物学性质。

    3）纳米材料及其制造工艺；2学时

    纳米材料分为纳米颗粒、纳米纤维、纳米薄膜和纳米块体材料及纳米复合材料等，主要介绍纳米纤维。纳米纤维可以由多种材料制备而成，包括聚合物、无机物、碳纳米管等，具有一些独特的物理和化学性质，其制造工艺通常包括静电纺丝法、溶液旋转法、化学气相沉积法等。此外，讲述纳米材料的未来展望。

    4）微纳米流动理论与控制技术；2学时

    微纳米流动理论与控制技术主要研究微观尺度下流体在微纳米尺度通道中的行为和调控方法。在微纳米尺度下，流体的行为和传统宏观尺度下存在显著差异，流体的粘性效应表面张力效应和量子效应等会显著影响流体的行为。流体力学的相关理论都会因为尺度效应产生变化。由于通道尺度与流体分子自由程相当，纳米尺度下的流体剪切、扩散和渗透都会呈现出非常复杂的行为，微纳米流动控制技术就是基于微流体芯片、微管道等微纳米结构结合外部场控制和表面修饰手段实现对流体的精确控制。

    5）课堂练习与讨论；2学时

    6）微纳米检测技术；2学时

    微纳米检测技术是一种用于在微观和纳米尺度下进行精确检测和分析的技术主要包括：原子力显微镜（AFM）、扫描隧道显微镜（STM）、扫描电子显微镜（SEM）、透射电子显微镜（TEM）、X射线衍射（XRD）等。

    第二部分: 过程微设备与微结构成型装备，学时数为20。

    7）典型过程微设备结构原理及应用；4学时

    主要介绍微型过程装备包括微反应器、微换热器、微混合器、微泵、微阀、微分离器等的基本概念、工作原理、及其应用选型等

    8）课堂练习与讨论；2学时

    微注塑成型技术及装备；6学时

    9）注塑成型技术基础；2学时

    注塑成型技术是一种常见的塑料加工方法，通过将加热后的聚合物熔体注射到模具中，经冷却凝固后形成所需产品，通常包括充模、压模、注射和冷却四个步骤。其关键工艺参数包括注射压力、注射时间、注塑温度、保压时间与压力、背压等。通过注塑机选型、关键工艺参数优化以及模具结构设计提高产品的质量。

    10）微注塑机械工作原理及结构设计；4学时

    高分子材料注塑成型装备包括注塑机、模具和其他附件。微型注塑机照驱动方式的不同可分为液压/气压式驱动、全电式驱动和油电复合式驱动微注塑机；按照注射系统结构的不同可分为单阶型(如单螺杆式)、双阶型(如螺杆螺杆式、柱塞-柱塞式和柱塞-螺杆式等)以及三阶型微注塑机。在微注塑机设计中，注塑系统的主要功能是完成塑料物料的加料输送、熔融塑化、计量注射等，而微型塑料制品的生产需要更高的注射压力、更短的成型周期以及更高的塑化质量，这无疑对注塑系统的设计是一个比较大的挑战。注塑系统的可靠性直接影响微型塑料制品成型质量的高低。

    微挤出成型工艺与装备；6学时

    11）挤出成型工艺基础；2学时

    挤出成型是聚合物熔体在螺杆或柱塞挤压作用下通过一定形状口模并成型的连续生产方式，所得制品是具有恒定截面形状的连续型材。在经过机器预热、预料加入、熔融塑化、熔体输送、口模成型等步骤后成型产品，在生物医疗、通信、农业滴灌、精细化工等领域有着巨大的潜在应用价值。

    12）微挤出机械结构原理及应用；4学时

    微挤出机械由挤出系统、传动系统、加热冷却系统和控制系统等几部分组成，其中挤出系统是关键部分，它包括加料装置：向挤出机料筒连续均匀供料的装置；料筒：是受热受内压的金属圆筒，物料的熔融塑化和压缩都是在料筒中进行的；螺杆：安装在料筒内可以转动且带有螺槽的金属杆，是实现固体物料输送、熔融塑化和熔体输送的重要部件；机头：口模和料筒的过渡连接部分，口模是制品的成型部件，通常机头和口模是一个整体，习惯上统称机头。与传统挤出成型设备不同的是微结构挤出成型设备对口模和附属设备的要求更高，具体表现在其口模尺寸更小，精度更高，需要对附属设备进行更精确的控制等。

    13）课堂练习与讨论；2学时

    14）课程大作业；2学时
