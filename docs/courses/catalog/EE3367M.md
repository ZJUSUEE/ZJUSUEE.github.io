# 特种电机及驱动技术

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 特种电机及驱动技术<br><small>EE3367M</small> | 车辆 · 26级<br>**专业选修 · 模块选修（绿色动力）** |

## 课程简介

??? abstract "展开查看"

    本课程主要介绍现代社会中的新颖特种电机及其驱动技术，这些电机及其驱动技术所具有的特点，掌握这些技术的一些基本方法,目前国内外各个领域对这些新颖电机及驱动技术与系统的应用状况及发展趋势。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

课程考核方式：研究报告+Poster+平时分

成绩评定方式：研究报告 40%；Poster 40%；平时分 20%

### 课程大纲

??? abstract "展开查看"

    1）绪论（课程介绍）：2学时

    【主要内容】：

    本课程向学生介绍电机学科各领域，使学生初步认识：

    1．特种电机分类

    2．特种电机及驱动技术的应用

    介绍课程的教学目标、课程内容、教学安排、作业及报告的要求。介绍现代特种电机及其驱动的基本情况、分类以及在航天领域、地面交通、水上运输、工业、信息设备、系统工程与自动化、军事、民用、医疗与其它各个方面的大概应用情况。

    【目标及要求】：

    要求学生了解浙大电气工程学院在电机方向上为我国取得的重大贡献、了解特种电机的分类、并检索阅读特种电机驱动技术的资料。

    【课程思政】：

    讲解浙大电气工程学院提出的双水内冷技术为我国做出的贡献，帮助学生了解电机制造业在国民生产、国防军工等领域的重要作用，帮助学生树立努力学习课程知识的信念。

    2）无刷直流电机及其驱动控制技术：2学时

    【主要内容】：

    本课程向学生介绍无刷直流电机及其驱动控制技术，使学生掌握直流无刷电机种类、原理、特点、控制方式、驱动电路、大功率永磁无刷电机研究的主要问题以及主要应用场合等。

    1．无刷直流电机系统组成

    2．无刷直流电机系统的工作原理

    3．无刷直流电机转子位置信号的检测

    4．无刷直流电机控制及其实现

    【目标及要求】：

    1．了解直流电机的发展前景

    2．了解无刷直流电机的分类和应用

    3．检索阅读直流电机驱动技术的资料

    【课程思政】：

    无

    3）永磁同步电机及矢量控制：2学时

    【主要内容】：

    本课程向学生介绍永磁同步电机及矢量控制技术，具体内容如下：

    1．永磁同步电机结构

    2．永磁同步电机数学模型

    3．永磁同步电机矢量控制技术

    4．直流无刷电机与永磁同步电机的运行控制比较

    【目标及要求】：

    1．掌握永磁同步电机结构、特点、数学模型建立、矢量控制方式。

    2．了解三次谐波在调制策略中的应用以及在永磁电机设计中的应用。

    3．检索阅读同步磁阻电机的资料

    【课程思政】：

    从永磁直驱风力发电机的案例出发，讲解永磁电机对国家应用发展的重要性，帮助学生树立民族自信的政治观念。

    4）内置式永磁同步、同步磁阻电机：2学时

    【主要内容】：

    本课程向学生介绍内置式永磁同步、同步磁阻电机，具体内容如下：

    1．内置式永磁同步电机结构

    2．内置式永磁同步电机数学模型

    3．内置式永磁同步电机基本控制方法

    4．内置式永磁同步电机矢量控制系统

    5．同步磁阻电机结构

    6．同步磁阻电机数学模型

    7．同步磁阻电机矢量控制

    8．同步磁阻电机与永磁同步电机的比较

    【目标及要求】：

    1．掌握内置式永磁同步电机结构特征、数学模型、基本控制方法和矢量控制系统。2．掌握同步磁阻电机结构特征、数学模型和矢量控制系统。

    【课程思政】：

    从高铁永磁牵引电机的案例出发，讲解永磁电机对国家应用发展的重要性，帮助学生树立家国情怀。

    5）开关磁阻电机：2学时

    【主要内容】：

    本课程向学生介绍开关磁阻电机，具体内容如下：

    1.开关磁阻电机组成

    2.开关磁阻电机原理

    3.开关磁阻电机的基本电磁关系

    4.开关磁阻电机控制系统组成

    【目标及要求】：

    1.掌握开关磁阻电机的基本特征、基本的结构、工作原理、控制方式、驱动电路。2.了解开关磁阻电机主要应用场合以及开关磁阻电机的原理与优点等等。

    【课程思政】：

    无

    6）定子永磁型电机：2学时

    【主要内容】：

    本课程向学生介绍定子永磁型电机，具体内容如下：

    1.双凸极永磁电机结构

    2.双凸极永磁电机工作原理

    3.电励磁双凸极电机、混合励磁双凸极电机

    4.磁通切换型永磁电机、磁通反向型永磁电机

    【目标及要求】：

    1.掌握双凸极永磁电机的基本特征、结构、工作原理及其优缺点等等，

    2.查阅关于多种定子永磁型电机的拓扑结构及运行原理的文章。

    【课程思政】：

    无

    7）磁场调制类电机：2学时

    【主要内容】：

    本课程向学生介绍磁场调制类电机，具体内容如下：

    1.磁场调制永磁电机发展历史

    2.磁场调制永磁电机结构与拓扑

    3.磁场调制永磁电机工作原理与性能分析

    4.磁场调制永磁电机应用前景与发展趋势

    【目标及要求】：

    1.查阅关于掌握磁场调制永磁电机的结构与拓扑、工作原理、应用前景、优缺点及其发展趋势的文献。

    【课程思政】：

    无

    8）盘式电机、直线电机：2学时

    【主要内容】：

    本课程向学生介绍盘式电机、直线电机，具体内容如下：

    1.盘式电机结构特点

    2.盘式永磁同步电机

    3.盘式轮毂电机

    4.直线电机结构特点

    5.直线感应电机

    6.直线直流电机

    7.直线同步电机

    8.直线步进电机

    9.直线电机的应用

    【目标及要求】：

    1.掌握盘式电机和直线电机的基本特征、基本的结构、工作原理、控制方式、驱动电路、主要应用场合及其优缺点等等。

    【课程思政】：

    无

    9）横向磁通永磁电机：2学时

    【主要内容】：

    本课程向学生介绍横向磁通永磁电机，具体内容如下：

    1.横向磁通永磁电机结构

    2.横向磁通永磁电机工作原理

    3.横向磁通永磁电机优缺点

    4.横向磁通永磁电机减小漏磁的方法

    【目标及要求】：

    1.掌握横向磁通永磁电机的基本特征、基本的结构、工作原理、控制方式、驱动电路、主要应用场合及其优缺点等等。

    【课程思政】：

    无

    10）步进电机与伺服电机：2学时

    【主要内容】：

    本课程向学生介绍步进电机与伺服电机，具体内容如下：

    1．步进电机简介及结构

    2．步进电机简介及结构

    3．小步距角的步进电机

    4．反应式步进电机的特性

    5．直流伺服电机

    6．交流异步伺服电机

    7．交流永磁伺服电机

    8．伺服电机的选择

    【目标及要求】：

    1.掌握步进与伺服电机的结构、工作原理、运行特性、驱动电路、控制方法

    2.要求能够针对某种特殊应用进行电机与驱动器的选型，编写相应的控制程序。

    【课程思政】：

    从伺服电机的案例出发，讲解伺服电机在航空航天领域的应用，帮助学生树立科技报国信念。

    11）自整角机与旋转变压器：2学时

    【主要内容】：

    本课程向学生介绍自整角机与旋转变压器，具体内容如下：

    1.控制类自整角机工作原理

    2.控制类自整角机的差动运行

    3.控制类自整角机的性能指标

    4.旋转变压器结构

    5.正余弦旋转变压器

    【目标及要求】：

    1.掌握自整角机的基本原理、了解自整角机的性能指标，能对某一特种应用场合进行自整角机选型；

    2.掌握正余弦旋转变压器基本原理及其驱动接口电路，能够针对不同电机进行旋转变压器选型，设计接口电路。

    【课程思政】：

    无

    12）非电磁类电机：2学时

    【主要内容】：

    本课程向学生介绍非电磁类电机，具体内容如下：

    1.超声波电动机的基本原理

    2.超声波电动机的常见结构与分类

    3.行波型超声波电动机的驱动控制

    4.超声波电机存在的问题及研究重点

    5.静电电动机

    6.磁致伸缩驱动器

    【目标及要求】：

    1.掌握超声波的基本原理、常见结构与分类、驱动控制

    2.能够针对某一特种应用场合开展初步设计，了解静电电动机与磁致伸缩驱动器基本原理。

    【课程思政】：

    无

    13）新能源发电：2学时

    【主要内容】：

    本课程向学生介绍新能源发电有关技术，具体内容如下：

    1.风力发电发展概况

    2.风力发电机与变流器

    3.风力发电未来发展方向

    4.太阳能发电发展概况

    5.光伏发电系统结构

    6.光伏发电关键控制技术

    【目标及要求】：

    1.查阅不同新能源发电领域的发展概况、系统组成以及关键技术的文献。

    【课程思政】：

    讲解我国自主产权的风力发电机的应用和发展概况，帮助学生树立家国情怀。

    14）交通领域电机：2学时

    【主要内容】：

    本课程向学生介绍交通领域有关电机，具体内容如下：

    1.多电/全电舰船的电力推进系统

    2.电力推进的应用

    3.轨道交通中的牵引电机

    4.城市轨道交通的牵引传动系统

    5.汽车中的电机

    【目标及要求】：

    1.查阅交通领域中特种电机的文献。

    2.掌握学习新领域新技术的方法。

    【课程思政】：

    讲解我国高铁永磁牵引电机,帮助学生树立家国情怀。

    15）国防、工业、民用领域电机应用：2学时

    【主要内容】：

    本课程向学生介绍国防、工业、民用领域电机应用，具体内容如下：

    1.飞机用特种电机与驱动技术

    2.电动汽车用特种电机与驱动技术

    3.家用电器用特种电机与驱动技术

    4.军用特种电机与驱动技术

    【目标及要求】：

    掌握应用不同领域的特种电机与驱动技术的特点，掌握学习新领域新技术的方法

    【课程思政】：

    讲解我国飞机用特种电机以及探月用特种电机,从国防意识角度出发，帮助学生科技报国信念。

    16）课堂讨论与成果展示：2学时

    【主要内容】：

    本节课程讨论特种电机与驱动技术最新发展前沿，展示完成的研究报告和poster。

    【目标及要求】：

    介绍调研学习的相关领域发展概况和前沿信息，并具有自身的思考和展望。

    【课程思政】：

    配合课程思政，进行研讨。
