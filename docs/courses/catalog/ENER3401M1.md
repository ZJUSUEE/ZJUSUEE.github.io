# 汽车理论与自动驾驶

## 课程信息 {#course-information}

| 课程名称／课程号 | 适用范围与修读要求 |
| --- | --- |
| 汽车理论与自动驾驶<br><small>ENER3401M1</small> | 车辆 · 26级<br>**专业必修** |

## 课程简介

??? abstract "展开查看"

    《汽车理论与自动驾驶》是车辆工程专业的核心课程。课程内容聚焦车辆动力学与自动驾驶前沿技术的融合，主要包括轮胎力学、车辆动力性、制动性与操纵稳定性等动力学基础，并系统讲授自动驾驶环境感知、行为决策、运动规划与车辆控制等核心模块。课程特别着力于轨迹跟踪控制理论，重点解析纯跟踪、Stanley、模型预测控制等经典与现代控制方法的原理与设计。通过本课程学习，学生能够从整车系统角度出发，理解智能车辆性能的评价指标与分析方法，掌握基于动力学约束的跟踪控制策略设计，以及相关关键技术参数的确定理论，为从事智能车辆系统的综合设计、研发与集成打下坚实基础。

    来源：[教务网](https://zdbk.zju.edu.cn/)。

## 课程内容

### 分数构成

平时作业和测验分别占40%、60%，具体如下：

1) 平时作业包括：读书报告、建模仿真、实验报告；

2) 测验包括：轮胎模块、动力学模块、感知算法、规划模块、轨迹控制。

### 课程大纲

??? abstract "展开查看"

    本课程共16次课，围绕“车辆动力学建模”与“自动驾驶感知-规划-控制”两条主线展开，具体安排如下：

    （一）车辆动力学概论与纵向动力学（第1-5次课）

    车辆性能分析与设计概论；轮胎力学模型（Pacejka魔术公式、线性/非线性区特性）；动力传动系统建模（外特性、速比、行驶阻力平衡）；制动系统力学模型（制动力分配I曲线、ABS/ESC原理）；纵向动力学仿真实践。

    （二）车辆侧向与垂向动力学（第6-10次课）

    侧向力学基础与阿克曼转向几何；线性二自由度单轨模型（侧偏角、横摆角速度响应、转向特性）；侧向动力学仿真与系统辨识实践；三自由度侧向-横摆-侧倾耦合模型与侧翻分析；垂向动力学模型（1/4与半车模型、悬架特性、路面激励传递）。

    （三）自动驾驶感知与规划（第11-14次课）

    环境感知基础：摄像头与激光雷达工作原理、车道线检测、点云分割聚类；车辆运动预测：运动学模型（CV/CTRV）、基于物理与数据驱动的预测方法；运动规划：图搜索（Dijkstra/A\*）、采样方法（RRT）、基于优化的平滑轨迹生成、数据驱动规划；感知规划算法实践（CARLA/ROS）。

    （四）轨迹跟踪控制与综合实践（第15-16次课）

    轨迹跟踪控制：纯跟踪（Pure Pursuit）、Stanley控制器、PID纵向控制、模型预测控制（MPC）；轨迹跟踪控制实践；规划-控制联合仿真综合测试。
